Every component of the shared toolkit on one page. Chapter authors: this file is also a working example — view source next to README.md.

1. Interactive B-tree / B+tree

Type a key and press Enter or a button. Every frame comes from the real model (BTViz.models.BTree / BPlusTree), so you can step backwards, scrub and change speed. Tick Predict to be asked before a leaf overflows.

2. Slotted page (PageView)

Slots grow forward from the header, cells grow backward from the end of the page.

3. Binary search (ArrayView + code panel)

4. TreeView extras: copy-on-write DAG, page ids, high keys, right links, latches

5. Swim lanes (Lanes): you choose who steps next

6. Log timeline with a crash scrubber (Timeline)

7. Buffer pool (FrameGrid), allocator slots (MemoryMap), bytes (HexGrid)

8. Charts (Chart) and point graphs (GraphView)
