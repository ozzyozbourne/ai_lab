    1The API in two pictures

    Everything public is re-exported by mujoco_warp/__init__.py from modules under _src/. The names are identical in the 4.0.1 wheel and in the development tree at 8f5b9f1; a few signatures differ (flagged below as dev tree adds). __init__.py ends with _differentiable(locals()), which wraps every public function for the experimental differentiability API (_src/diff.py, Ch 29 §3).

    Tip

    Every function takes (m, d) first and works on all worlds at once. A function that returns nothing writes its results into d; read them with .numpy() only outside the hot loop (Ch 6 §10).

    Version note: dev tree vs 4.0.1

    The development tree at 8f5b9f1 exports the same names. Differences in signatures: collision gains ctx, woke and sort_contacts; the broadphases gain woke; fwd_velocity and rne gain cfrc_int_in (and skip_com_vel); create_render_context gains backend (OptiX, Ch 27 §13); DynType and GainType gain PID. The dev tree also adds _src/sort.py and _src/render_optix.py (repository tour).

    Pitfall: two useful enums are private

    SleepPolicy and EqType live in mujoco_warp._src.types but are not exported, so code that uses them is private API (Example 1.7 imports them that way, Ch 1 §7).

    4Command-line tools

    The wheel installs three scripts (pyproject.toml [project.scripts]): mjwarp-testspeed (mujoco_warp.testspeed:main), mjwarp-viewer (mujoco_warp.viewer:main) and mjwarp-record (mujoco_warp.record:main). All three take the MJCF path as their first argument and use absl flags. The viewer and recorder need the viewer extra. Usage and pitfalls: Ch 5 §9 (viewer, record) and Ch 25 §4 (testspeed).

    mjwarp-viewer

    mjwarp-viewer path/to/model.xml                     # MJWarp physics, MuJoCo passive viewer
mjwarp-viewer path/to/model.xml --engine c          # C MuJoCo physics in the same window
mjwarp-viewer path/to/model.xml -o "opt.solver=cg"  # override options
mjwarp-viewer path/to/model.xml --viewer viser      # browser viewer (pip install "mjviser>=0.0.13")
    viewer.py (4.0.1). Plus the shared flags; viewer.py sets the default of --nworld to 1.
