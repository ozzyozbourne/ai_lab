Callouts

Four kinds, with an optional title. Use them sparingly: one per idea that the reader must not miss.

Note

The EAL parses its own options first; rte_eal_init() returns how many argv entries it consumed.

Tip

Use --file-prefix to run several DPDK processes side by side.

Warning

Never bind the NIC that carries your SSH session to a DPDK driver.

Pitfall

rte_eth_tx_burst() may send fewer packets than asked. Free the rest or you leak mbufs.

Code

A code block with a file header

hello_dpdk.cC
#include <stdio.h>
#include <rte_eal.h>
#include <rte_ethdev.h>
#include <rte_version.h>

/* Smallest possible DPDK program. */
int main(int argc, char **argv)
{
	int ret = rte_eal_init(argc, argv);   // parse EAL options
	if (ret < 0)
		rte_exit(EXIT_FAILURE, "EAL init failed\n");
	printf("%s: %u lcores, %u ports, burst=%d, mask=0x%x\n", rte_version(),
	       rte_lcore_count(), rte_eth_dev_count_avail(), 32, 0xffu);
	struct rte_mbuf *pkts[32];
	(void)pkts;
	return rte_eal_cleanup();
}
