Chapter 10

Parsing and Building Packets: lib/net, Checksums and l2fwd

Until now our packets were opaque blobs that went in one port and out another. In this chapter you open them. You will read every header of a frame with the lib/net structs, without ever touching a byte the packet does not have, compute and verify Internet checksums by hand and with the library, build ARP, ICMP, UDP, IPv6, VLAN, QinQ and VXLAN frames from scratch, define your own header the DPDK 26.11 way, and then take apart l2fwd, the classic minimal forwarder, down to its TX buffer and drain timer.

1From bytes to structs

A packet in an mbuf is just bytes: rte_pktmbuf_mtod(m, void *) gives you the address of the first one (ch7). Protocols define what those bytes mean: the first 6 are the destination MAC, the next 6 the source MAC, then a 2-byte type, and so on. lib/net turns each protocol header into a C struct whose members sit at exactly the right offsets, so instead of computing p[23] you write ip->next_proto_id. Parsing is "point a struct pointer at the right offset"; building is "point a struct pointer at fresh space and fill the members".

The structs live in lib/net/, one header per protocol. The ones this chapter uses:

Two details in those definitions matter. First, most of them are declared struct __rte_aligned(2) __rte_packed_begin rte_ipv4_hdr { ... } __rte_packed_end;: packed so the compiler inserts no padding, and aligned to 2 because that is all a frame can promise. The Ethernet header is 14 bytes, so if the frame starts on a 4-byte boundary the IPv4 addresses (offset 26 and 30) are only 2-byte aligned. Second, every multi-byte field has a type like rte_be16_t or rte_be32_t. Those are plain uint16_t/uint32_t typedefs whose name tells you the value is big-endian (network order). The compiler will not stop you mixing them up; the name is a reminder for you.

2Byte order

Network protocols send multi-byte numbers most significant byte first (network byte order, big-endian). x86 and most Arm systems store them least significant byte first. So the ether_type 0x0800 sits in the packet as bytes 08 00; if you load it as a uint16_t on x86 you get 0x0008. Every multi-byte header field needs a conversion when you read it into a host variable or write a host value into it. DPDK's helpers are in lib/eal/include/generic/rte_byteorder.h:

RTE_BE16() is evaluated by the compiler, so comparing a field against RTE_BE16(constant) costs nothing at run time; converting the field instead (rte_be_to_cpu_16(f) == constant) costs one byte-swap instruction. Both are correct. One-byte fields (time_to_live, next_proto_id, icmp_type) have no byte order. And one 16-bit field is the exception to the rule: the checksum, which section 6 explains.

Pitfall: RTE_IPV4 is host order

RTE_IPV4(10,10,0,2) is the integer 0x0a0a0002, which is right for comparisons against rte_be_to_cpu_32(ip->dst_addr) or for LPM tables (ch18), but wrong if stored directly into a header. On x86 ip->dst_addr = RTE_IPV4(10,10,0,2) sends the packet to 2.0.10.10.

3Ethernet, VLAN and ARP

A MAC address is struct rte_ether_addr { uint8_t addr_bytes[6]; }, aligned to 2. lib/net/rte_ether.h gives you the helpers you would otherwise write yourself:

  • rte_ether_addr_copy(from, to): copy 6 bytes (note the argument order: source first). rte_is_same_ether_addr(a, b) compares.
  • rte_is_broadcast_ether_addr(), rte_is_multicast_ether_addr() (lowest bit of the first byte), rte_is_unicast_ether_addr(), rte_is_zero_ether_addr(), rte_is_local_admin_ether_addr() (bit 1 of the first byte, as in 02:...), rte_is_valid_assigned_ether_addr().
  • rte_ether_format_addr(buf, size, &mac) prints 02:00:00:00:00:01 into a buffer of RTE_ETHER_ADDR_FMT_SIZE; rte_ether_unformat_addr("02:00:00:00:00:01", &mac) parses one (it also accepts the XXXX:XXXX:XXXX form).
  • rte_eth_random_addr(bytes): a random, unicast, locally administered address. mini_l2fwd.c uses it for a fake sender.

A VLAN tag (802.1Q) is 4 bytes inserted between the source MAC and the ether_type: the ether_type position now holds the TPID 0x8100, then comes vlan_tci and the real ether_type in eth_proto. QinQ (802.1ad) stacks two tags; the outer "service" tag uses TPID 0x88a8 (RTE_ETHER_TYPE_QINQ; older gear uses 0x9100, RTE_ETHER_TYPE_QINQ1). Each tag you skip moves the L3 header 4 bytes further, which is why a parser loops on the ether_type. ARP (struct rte_arp_hdr, ether_type 0x0806) is the "who has 10.10.0.2? tell 10.10.0.1" message that maps IPv4 addresses to MACs; ch30's router answers it.

4The IPv4 header in detail

Five fields of struct rte_ipv4_hdr need care:

  • version_ihl: version in the high nibble (must be 4), header length in 32-bit words in the low nibble. rte_ipv4_hdr_len(ip) returns (version_ihl & RTE_IPV4_HDR_IHL_MASK) * 4: 20 without options, up to 60. RTE_IPV4_VHL_DEF is 0x45 for building. An IHL below 5 is invalid.
  • total_length: IP header plus payload. A frame can be longer than this (Ethernet pads short frames to 60 bytes), but never shorter. The L4 length is total_length - rte_ipv4_hdr_len(ip), not "whatever is left in the mbuf".
  • fragment_offset: three flag bits and a 13-bit offset in 8-byte units. Test with RTE_IPV4_HDR_DF_FLAG, RTE_IPV4_HDR_MF_FLAG and RTE_IPV4_HDR_OFFSET_MASK after rte_be_to_cpu_16(). Only the fragment with offset 0 contains the L4 header; ch19 reassembles fragments.
  • time_to_live: a router decrements it, drops the packet at 0, and must update the checksum (section 6).
  • hdr_checksum: covers the IP header only.

5IPv6 in DPDK 26.11

IPv6 has a fixed 40-byte header with no checksum, 128-bit addresses, and optional extension headers chained through the "next header" field. DPDK introduced its IPv6 address type in 24.11 and removed the last of the old definitions in 26.11, so code from older tutorials needs changes:

  • Addresses are struct rte_ipv6_addr { uint8_t a[16]; } everywhere (net, LPM6, FIB6, RIB6). Initialise with RTE_IPV6(0xfd00, 0x10, 0, 0, 0, 0, 0, 1), which takes eight 16-bit groups like the textual form; compare with rte_ipv6_addr_eq(&a, &b); print with RTE_IPV6_ADDR_FMT and RTE_IPV6_ADDR_SPLIT(&a). The old uint8_t[16] APIs and macros such as RTE_LPM6_IPV6_ADDR_SIZE are gone (release_26_11.rst, Removed Items).
  • struct rte_ipv6_hdr has no version/traffic-class/flow-label bitfields any more (bitfield order differs between compilers and endianness). You read and write the 32-bit vtc_flow as a whole and mask:

Extension headers sit between the IPv6 header and the L4 header. rte_ipv6_get_next_ext(p, proto, &ext_len) looks at one: if proto is an extension (hop-by-hop 0, routing 43, fragment 44, destination options 60, AH 51), it returns the next protocol and its length; otherwise -EINVAL, meaning "you have reached the upper layer". rte_net_skip_ip6_ext(proto, m, &off, &frag) does the whole walk on an mbuf and tells you whether it saw a fragment header.

Warning: the IPv6 L4 checksum helpers assume no extension headers

rte_ipv6_udptcp_cksum() and rte_ipv6_udptcp_cksum_verify() build the pseudo-header from ip6->payload_len and ip6->proto. With an extension header, payload_len includes the extension bytes and proto names the extension, so both are wrong for the pseudo-header. parse_pcap.c shows the effect on frame #6 (l4csum(naive)=BAD) and the fix: verify against a copy of the header with payload_len set to the real L4 length and proto set to the final protocol.

6The Internet checksum

IPv4, UDP, TCP and ICMP all use the same 16-bit checksum (RFC 1071). It is simple and cheap, and it has one property that confuses everybody the first time: it does not care about byte order. The algorithm:

  1. Treat the data as a sequence of 16-bit words (pad an odd last byte with a zero).
  2. Add them all with one's-complement addition: whenever the sum overflows 16 bits, the carry is added back into the low bits (end-around carry). In practice you add into a 32-bit accumulator and fold at the end: sum = (sum & 0xffff) + (sum >> 16), repeated until it fits.
  3. Invert the bits. That value goes into the checksum field, which was 0 during the sum.
  4. The receiver sums everything including the checksum. Because x + ~x = 0xffff, a correct packet sums to 0xffff.

UDP and TCP: the pseudo-header

The UDP and TCP checksums protect more than their own header: they also cover a pseudo-header made of the IP source and destination address, the protocol number and the L4 length. It is never transmitted; both ends build it from the IP header. That way a packet delivered to the wrong address fails its L4 checksum even if the IP checksum was "fixed" along the way.

0x3582 + 0x76d8 = 0xac5a, inverted 0x53a5. The odd 3-byte payload was padded with a zero byte for the sum (but not sent). Flipping one payload bit, or only the IP destination, both make rte_ipv4_udptcp_cksum_verify() return -1.

Two UDP special cases: over IPv4 a checksum of 0 means "not computed" (VXLAN uses that for its outer UDP header), so a computed 0 is sent as 0xffff, the other representation of zero in one's complement. rte_ipv4_udptcp_cksum() does that for you. Over IPv6 the UDP checksum is mandatory.

Incremental update (RFC 1624)

A router that decrements the TTL does not need to re-sum the whole header. If one 16-bit word changes from m to m', the new checksum is HC' = ~(~HC + ~m + m') (RFC 1624, equation 3). TTL shares its word with the protocol byte, so 0x4011 becomes 0x3f11:

code/expected_output.txt (cksum_lab section 6)
== 6. router step: TTL 64 -> 63, incremental update (RFC 1624 eqn. 3)

  full recompute = 0xb961   incremental = 0xb961   MATCH

The incremental result equals a full recompute. This is how l3fwd-style routers keep the TTL decrement cheap; exercise 2 extends it to a changed destination address, which also touches the UDP checksum.

7Safe parsing

Packets come from the outside world. Some are truncated, some lie in their length fields, some are crafted to crash you. A parser that reads ip->total_length from a 24-byte frame reads whatever memory follows the packet. Four rules prevent that:

  1. Check before you dereference. Before casting a pointer to a header at offset off, make sure off + sizeof(header) <= length.
  2. Validate the fields you use to move on: IPv4 version and IHL ≥ 5, total_length between the header length and the bytes you have, IPv6 payload_len, the TCP data offset, extension-header lengths.
  3. Use the protocol's length, not the buffer's, for the next layer (Ethernet padding is not payload).
  4. Do not assume one segment. In a multi-segment mbuf (jumbo frames, ch7) rte_pktmbuf_mtod_offset() is only valid inside the first segment's data_len, not pkt_len.

rte_pktmbuf_read(m, off, len, buf) in lib/mbuf/rte_mbuf.h implements rules 1 and 4 in one call. If [off, off+len) is inside the first segment it returns a pointer straight into the mbuf (no copy, just a compare). If the bytes exist but span segments, it copies them into your buf and returns buf. If the packet is too short it returns NULL. rte_net_get_ptype() uses it internally for every header.

/* ---- a tiny line builder so each frame prints on one line ---- */
static char line[512];
static size_t line_len;

static void
out(const char *fmt, ...)
{
	va_list ap;

	if (line_len >= sizeof(line))
		return;
	va_start(ap, fmt);
	line_len += vsnprintf(line + line_len, sizeof(line) - line_len, fmt, ap);
	va_end(ap);
	if (line_len > sizeof(line))
		line_len = sizeof(line);
}

/*
 * THE one rule of safe parsing: never dereference a header before you know
 * the packet really contains it.  rte_pktmbuf_read() does the check for us:
 *  - if [off, off+len) lies inside the first segment it returns a pointer
 *    straight into the mbuf data (no copy, the fast path);
 *  - if the bytes exist but span segments it copies them into 'buf' and
 *    returns buf;
 *  - if the packet is shorter than off+len it returns NULL.
 * Always pass a buffer at least 'len' bytes long.
 */
#define HDR(m, off, type, buf) \
	((const type *)rte_pktmbuf_read((m), (off), sizeof(type), (buf)))

/* A scratch area big enough for a whole L4 segment when it must be copied. */
static uint8_t l4_copy[2048];

static void
ip4_str(rte_be32_t a, char *s, size_t n)
{
	uint32_t h = rte_be_to_cpu_32(a);   /* network -> host order first */

	snprintf(s, n, "%u.%u.%u.%u", h >> 24, (h >> 16) & 0xff,
		 (h >> 8) & 0xff, h & 0xff);
}

static int parse_ether(const struct rte_mbuf *m, uint32_t off, int depth);

/* L4 for both IP versions. 'ip4'/'ip6' says which pseudo-header to use. */
static void
parse_l4(const struct rte_mbuf *m, uint32_t off, uint32_t l4_len, uint8_t proto,
	 const struct rte_ipv4_hdr *ip4, const struct rte_ipv6_hdr *ip6,
	 int depth)
{
	const void *l4;

	switch (proto) {
	case IPPROTO_UDP: {
		struct rte_udp_hdr ubuf;
		const struct rte_udp_hdr *u = HDR(m, off, struct rte_udp_hdr, &ubuf);

		if (u == NULL || l4_len < sizeof(*u)) {
			out(" | DROP: truncated UDP header");
			return;
		}
		out(":%u -> :%u UDP", rte_be_to_cpu_16(u->src_port),
		    rte_be_to_cpu_16(u->dst_port));
		break;
	}
	case IPPROTO_TCP: {
		struct rte_tcp_hdr tbuf;
		const struct rte_tcp_hdr *t = HDR(m, off, struct rte_tcp_hdr, &tbuf);

		if (t == NULL || l4_len < sizeof(*t)) {
			out(" | DROP: truncated TCP header");
			return;
		}
		out(":%u -> :%u TCP[%s%s] hlen=%u", rte_be_to_cpu_16(t->src_port),
		    rte_be_to_cpu_16(t->dst_port),
		    (t->tcp_flags & RTE_TCP_SYN_FLAG) ? "S" : "",
		    (t->tcp_flags & RTE_TCP_ACK_FLAG) ? "A" : "",
		    (t->data_off >> 4) * 4);
		break;
	}
	case IPPROTO_ICMP: {
		struct rte_icmp_hdr ibuf;
		const struct rte_icmp_hdr *ic = HDR(m, off, struct rte_icmp_hdr, &ibuf);

		if (ic == NULL || l4_len < sizeof(*ic)) {
			out(" | DROP: truncated ICMP header");
			return;
		}
		/* 26.11: RTE_ICMP_TYPE_ECHO_REQUEST (RTE_IP_ICMP_ECHO_* are gone) */
		if (ic->icmp_type == RTE_ICMP_TYPE_ECHO_REQUEST)
			out("ICMP echo-request id=0x%04x seq=%u",
			    rte_be_to_cpu_16(ic->icmp_ident),
			    rte_be_to_cpu_16(ic->icmp_seq_nb));
		else
			out("ICMP type=%u code=%u", ic->icmp_type, ic->icmp_code);
		break;
	}
	default:
		out(" proto=%u (not parsed)", proto);
		return;
	}

	/* Checksum: we need the whole L4 segment in contiguous memory. */
	if (l4_len > sizeof(l4_copy)) {
		out(" l4csum=skipped(too long)");
		return;
	}
	l4 = rte_pktmbuf_read(m, off, l4_len, l4_copy);
	if (l4 == NULL) {
		out(" | DROP: L4 shorter than the IP header claims");
		return;
	}
	if (proto == IPPROTO_UDP && ((const struct rte_udp_hdr *)l4)->dgram_cksum == 0) {
		/* UDP over IPv4 may omit the checksum (0 means "none"). */
		out(" l4csum=none");
	} else if (proto == IPPROTO_ICMP) {
		/* ICMP has no pseudo-header: plain sum over the message. */
		out(" l4csum=%s", rte_raw_cksum(l4, l4_len) == 0xffff ? "ok" : "BAD");
	} else if (ip4 != NULL) {
		out(" l4csum=%s",
		    rte_ipv4_udptcp_cksum_verify(ip4, l4) == 0 ? "ok" : "BAD");
	} else {
		/*
		 * rte_ipv6_udptcp_cksum*() build the pseudo-header from
		 * ip6->payload_len and ip6->proto. With extension headers both
		 * are wrong for the pseudo-header (payload_len includes the
		 * extensions, proto names the first extension). Fix a COPY of
		 * the header so the library sees what RFC 8200 8.1 asks for.
		 */
		struct rte_ipv6_hdr fixed = *ip6;

		fixed.payload_len = rte_cpu_to_be_16((uint16_t)l4_len);
		fixed.proto = proto;
		if (fixed.proto != ip6->proto)
			out(" l4csum(naive)=%s",
			    rte_ipv6_udptcp_cksum_verify(ip6, l4) == 0 ? "ok" : "BAD");
		out(" l4csum=%s",
		    rte_ipv6_udptcp_cksum_verify(&fixed, l4) == 0 ? "ok" : "BAD");
	}

	/* VXLAN: UDP destination port 4789, 8-byte header, then a whole frame. */
	if (proto == IPPROTO_UDP && depth == 0) {
		const struct rte_udp_hdr *u = l4;
		struct rte_vxlan_hdr vbuf;
		const struct rte_vxlan_hdr *vx;

		if (u->dst_port != RTE_BE16(RTE_VXLAN_DEFAULT_PORT))
			return;
		vx = HDR(m, off + sizeof(*u), struct rte_vxlan_hdr, &vbuf);
		if (vx == NULL) {
			out(" | DROP: truncated VXLAN header");
			return;
		}
		/* vx_vni holds the 24-bit VNI in its top 3 bytes. */
		out(" VXLAN vni=%u {", rte_be_to_cpu_32(vx->vx_vni) >> 8);
		parse_ether(m, off + sizeof(*u) + sizeof(*vx), depth + 1);
		out(" }");
	}
}

static void
parse_ipv4(const struct rte_mbuf *m, uint32_t off, int depth)
{
	uint8_t hbuf[60];                 /* max IPv4 header: IHL 15 * 4 */
	const struct rte_ipv4_hdr *ip;
	uint16_t hlen, total, frag, frag_off;
	char s[16], d[16];

	ip = HDR(m, off, struct rte_ipv4_hdr, hbuf);
	if (ip == NULL) {
		out("IPv4 | DROP: truncated IPv4 header (need %zu bytes at offset %u, frame has %u)",
		    sizeof(*ip), off, rte_pktmbuf_pkt_len(m));
		return;
	}
	if ((ip->version_ihl >> 4) != 4) {
		out("IPv4 | DROP: version %u", ip->version_ihl >> 4);
		return;
	}
	hlen = rte_ipv4_hdr_len(ip);          /* (version_ihl & 0xf) * 4 */
	if (hlen < sizeof(*ip)) {
		out("IPv4 | DROP: IHL %u gives %u-byte header (< 20)",
		    ip->version_ihl & RTE_IPV4_HDR_IHL_MASK, hlen);
		return;
	}
	total = rte_be_to_cpu_16(ip->total_length);
	if (total < hlen || off + total > rte_pktmbuf_pkt_len(m)) {
		out("IPv4 | DROP: total_length %u does not fit", total);
		return;
	}
	if (hlen > sizeof(*ip)) {             /* re-read including options */
		ip = rte_pktmbuf_read(m, off, hlen, hbuf);
		if (ip == NULL)
			return;
		out("IPv4(+%u opt bytes) ", hlen - (unsigned int)sizeof(*ip));
	} else {
		out("IPv4 ");
	}
	ip4_str(ip->src_addr, s, sizeof(s));
	ip4_str(ip->dst_addr, d, sizeof(d));
	out("%s -> %s ttl=%u ipcsum=%s ", s, d, ip->time_to_live,
	    /* sum over a correct header INCLUDING its checksum is 0xffff */
	    rte_raw_cksum(ip, hlen) == 0xffff ? "ok" : "BAD");

	frag = rte_be_to_cpu_16(ip->fragment_offset);
	frag_off = (frag & RTE_IPV4_HDR_OFFSET_MASK) * RTE_IPV4_HDR_OFFSET_UNITS;
	if (frag & RTE_IPV4_HDR_MF_FLAG || frag_off) {
		out("frag(id=%u off=%u MF=%u) ", rte_be_to_cpu_16(ip->packet_id),
		    frag_off, !!(frag & RTE_IPV4_HDR_MF_FLAG));
		if (frag_off != 0) {
			/* only the first fragment carries the L4 header */
			out("proto=%u, no L4 header in this fragment", ip->next_proto_id);
			return;
		}
		if (ip->next_proto_id == IPPROTO_UDP) {
			/* L4 header is here, but the checksum covers all fragments */
			struct rte_udp_hdr ubuf;
			const struct rte_udp_hdr *u =
				HDR(m, off + hlen, struct rte_udp_hdr, &ubuf);
			if (u != NULL)
				out(":%u -> :%u UDP l4csum=needs-reassembly",
				    rte_be_to_cpu_16(u->src_port),
				    rte_be_to_cpu_16(u->dst_port));
			return;
		}
	}
	parse_l4(m, off + hlen, total - hlen, ip->next_proto_id, ip, NULL, depth);
}

static void
parse_ipv6(const struct rte_mbuf *m, uint32_t off, int depth)
{
	struct rte_ipv6_hdr hbuf;
	const struct rte_ipv6_hdr *ip6 = HDR(m, off, struct rte_ipv6_hdr, &hbuf);
	uint32_t vtc, plen, cur;
	int proto, i;
	char s[INET6_ADDRSTRLEN], d[INET6_ADDRSTRLEN];

	if (ip6 == NULL) {
		out("IPv6 | DROP: truncated IPv6 header");
		return;
	}
	if (rte_ipv6_check_version(ip6) != 0) {
		out("IPv6 | DROP: bad version");
		return;
	}
	plen = rte_be_to_cpu_16(ip6->payload_len);
	if (off + sizeof(*ip6) + plen > rte_pktmbuf_pkt_len(m)) {
		out("IPv6 | DROP: payload_len %u does not fit", plen);
		return;
	}
	/* 26.11: no bitfields; mask/shift the host-order vtc_flow word. */
	vtc = rte_be_to_cpu_32(ip6->vtc_flow);
	snprintf(s, sizeof(s), RTE_IPV6_ADDR_FMT, RTE_IPV6_ADDR_SPLIT(&ip6->src_addr));
	snprintf(d, sizeof(d), RTE_IPV6_ADDR_FMT, RTE_IPV6_ADDR_SPLIT(&ip6->dst_addr));
	out("IPv6 %s -> %s tc=0x%02x flow=0x%05x hlim=%u ", s, d,
	    (vtc & RTE_IPV6_HDR_TC_MASK) >> RTE_IPV6_HDR_TC_SHIFT,
	    (vtc & RTE_IPV6_HDR_FL_MASK) >> RTE_IPV6_HDR_FL_SHIFT,
	    ip6->hop_limits);

	/* Walk extension headers: rte_ipv6_get_next_ext() needs 2 bytes. */
	proto = ip6->proto;
	cur = off + sizeof(*ip6);
	for (i = 0; i < 8; i++) {
		uint8_t eb[2];
		const uint8_t *p = rte_pktmbuf_read(m, cur, 2, eb);
		size_t ext_len;
		int next;

		if (p == NULL)
			break;
		next = rte_ipv6_get_next_ext(p, proto, &ext_len);
		if (next < 0)
			break;                  /* proto is not an extension */
		out("ext(%d,%zuB) ", proto, ext_len);
		cur += ext_len;
		proto = next;
		if (cur > off + sizeof(*ip6) + plen) {
			out("| DROP: extension headers overrun the payload");
			return;
		}
	}
	parse_l4(m, cur, off + sizeof(*ip6) + plen - cur, (uint8_t)proto,
		 NULL, ip6, depth);
}

static void
parse_arp(const struct rte_mbuf *m, uint32_t off)
{
	struct rte_arp_hdr abuf;
	const struct rte_arp_hdr *a = HDR(m, off, struct rte_arp_hdr, &abuf);
	char sip[16], tip[16], sha[RTE_ETHER_ADDR_FMT_SIZE];

	if (a == NULL) {
		out("ARP | DROP: truncated");
		return;
	}
	ip4_str(a->arp_data.arp_sip, sip, sizeof(sip));
	ip4_str(a->arp_data.arp_tip, tip, sizeof(tip));
	rte_ether_format_addr(sha, sizeof(sha), &a->arp_data.arp_sha);
	if (a->arp_opcode == RTE_BE16(RTE_ARP_OP_REQUEST))
		out("ARP request: who has %s? tell %s (%s)", tip, sip, sha);
	else
		out("ARP op=%u %s -> %s", rte_be_to_cpu_16(a->arp_opcode), sip, tip);
}

/* Returns 0 if an L3 header was found, -1 otherwise. */
static int
parse_ether(const struct rte_mbuf *m, uint32_t off, int depth)
{
	struct rte_ether_hdr ebuf;
	const struct rte_ether_hdr *eth = HDR(m, off, struct rte_ether_hdr, &ebuf);
	uint16_t type;

	if (eth == NULL) {
		out("| DROP: shorter than an Ethernet header");
		return -1;
	}
	if (depth > 0) {
		char dst[RTE_ETHER_ADDR_FMT_SIZE];

		rte_ether_format_addr(dst, sizeof(dst), &eth->dst_addr);
		out("inner-eth dst=%s ", dst);
	}
	type = rte_be_to_cpu_16(eth->ether_type);
	off += sizeof(*eth);

	if (type == RTE_ETHER_TYPE_VLAN) {      /* one 802.1Q tag */
		struct rte_vlan_hdr vbuf;
		const struct rte_vlan_hdr *vh = HDR(m, off, struct rte_vlan_hdr, &vbuf);
		uint16_t tci;

		if (vh == NULL) {
			out("| DROP: truncated VLAN tag");
			return -1;
		}
		tci = rte_be_to_cpu_16(vh->vlan_tci);
		out("vlan=%u pcp=%u ", tci & 0xfff, tci >> 13);
		type = rte_be_to_cpu_16(vh->eth_proto);
		off += sizeof(*vh);
	}

	switch (type) {
	case RTE_ETHER_TYPE_IPV4:
		parse_ipv4(m, off, depth);
		return 0;
	case RTE_ETHER_TYPE_IPV6:
		parse_ipv6(m, off, depth);
		return 0;
	case RTE_ETHER_TYPE_ARP:
		parse_arp(m, off);
		return 0;
	default:
		/* QinQ (0x88a8) lands here: that is exercise 1 */
		out("ethertype 0x%04x not handled", type);
		return -1;
	}
}

/* Print what the library parser thinks of the same frame. */
static void
print_ptype(struct rte_mbuf *m)
{
	struct rte_net_hdr_lens hl = {0};
	char name[256];
	uint32_t ptype = rte_net_get_ptype(m, &hl, RTE_PTYPE_ALL_MASK);

	rte_get_ptype_name(ptype, name, sizeof(name));
	printf("      ptype=0x%08x %s\n", ptype, name);
	printf("      hdr_lens l2=%u l3=%u l4=%u", hl.l2_len, hl.l3_len, hl.l4_len);
	if (ptype & RTE_PTYPE_TUNNEL_MASK)
		printf(" tunnel=%u inner_l2=%u inner_l3=%u inner_l4=%u",
		       hl.tunnel_len, hl.inner_l2_len, hl.inner_l3_len,
		       hl.inner_l4_len);
	printf("\n");

	/*
	 * Sanity check: INNER_* bits without a TUNNEL_* bit make no sense.
	 * In 26.11 this happens for IPv4/ICMP: L4 "unknown" sends the parser
	 * into its inner-header code with proto = 1 (ICMP), which equals
	 * RTE_VXLAN_GPE_TYPE_IPV4, so the ICMP message is decoded as an inner
	 * IPv4 header. Asking only for the outer layers avoids that path.
	 */
	if ((ptype & (RTE_PTYPE_INNER_L2_MASK | RTE_PTYPE_INNER_L3_MASK |
		      RTE_PTYPE_INNER_L4_MASK)) != 0 &&
	    (ptype & RTE_PTYPE_TUNNEL_MASK) == 0) {
		ptype = rte_net_get_ptype(m, &hl, RTE_PTYPE_L2_MASK |
					  RTE_PTYPE_L3_MASK | RTE_PTYPE_L4_MASK);
		rte_get_ptype_name(ptype, name, sizeof(name));
		printf("      !! inner bits without a tunnel; outer layers only: ptype=0x%08x %s\n",
		       ptype, name);
	}
}

/* Build a 2-segment copy of 'src' split at byte 'split' and parse it. */
static void
segment_demo(struct rte_mempool *pool, const uint8_t *frame, uint16_t len,
	     uint16_t split)
{
	struct rte_mbuf *a = rte_pktmbuf_alloc(pool), *b = rte_pktmbuf_alloc(pool);
	struct rte_ipv4_hdr copy;
	const struct rte_ipv4_hdr *ip;

	if (a == NULL || b == NULL) {
		rte_pktmbuf_free(a);
		rte_pktmbuf_free(b);
		return;
	}
	memcpy(rte_pktmbuf_append(a, split), frame, split);
	memcpy(rte_pktmbuf_append(b, len - split), frame + split, len - split);
	rte_pktmbuf_chain(a, b);              /* a now owns b */

	printf("\n== a 2-segment packet: seg0 %u bytes + seg1 %u bytes (pkt_len %u)\n",
	       rte_pktmbuf_data_len(a), rte_pktmbuf_data_len(b),
	       rte_pktmbuf_pkt_len(a));
	printf("   IPv4 header needs bytes [14,34) but seg0 ends at %u:\n", split);
	printf("   rte_pktmbuf_mtod_offset(m, ip*, 14) would read %u bytes past seg0 (garbage)\n",
	       14 + 20 - split);
	ip = rte_pktmbuf_read(a, 14, sizeof(copy), &copy);
	printf("   rte_pktmbuf_read() returned %s, ttl=%u total_length=%u\n",
	       (const void *)ip == (void *)&copy ? "our stack copy" : "a pointer into the mbuf",
	       ip->time_to_live, rte_be_to_cpu_16(ip->total_length));
	line_len = 0;
	parse_ether(a, 0, 0);
	printf("   parse: %s\n", line);
	print_ptype(a);
	rte_pktmbuf_free(a);
}

int
main(int argc, char **argv)
{
	struct rte_mempool *pool;
	struct rte_mbuf *pkts[32];
	uint8_t first[256];
	uint16_t first_len = 0;
	unsigned int n = 0, idle = 0, i;
	int ret;

	ret = rte_eal_init(argc, argv);
	if (ret < 0)
		rte_exit(EXIT_FAILURE, "EAL init failed\n");
	if (rte_eth_dev_count_avail() < 1)
		rte_exit(EXIT_FAILURE, "need one port, e.g. --vdev=net_pcap0,rx_pcap=mixed.pcap,tx_pcap=/dev/null\n");

	pool = rte_pktmbuf_pool_create("ch10_parse", 1023, 32, 0,
				       RTE_MBUF_DEFAULT_BUF_SIZE, rte_socket_id());
	if (pool == NULL)
		rte_exit(EXIT_FAILURE, "mbuf pool: %s\n", rte_strerror(rte_errno));
	if (ch10_port_init(0, pool) < 0)
		rte_exit(EXIT_FAILURE, "port 0 init failed\n");

	/* net_pcap delivers the file once, then returns 0 forever. */
	while (idle < 100) {
		uint16_t nb = rte_eth_rx_burst(0, 0, pkts, 32);

		if (nb == 0) {
			idle++;
			continue;
		}
		idle = 0;
		for (i = 0; i < nb; i++) {
			struct rte_mbuf *m = pkts[i];

			n++;
			/* keep a copy of the first IPv4 frame for segment_demo() */
			if (first_len == 0 && rte_pktmbuf_data_len(m) <= sizeof(first) &&
			    rte_pktmbuf_mtod(m, struct rte_ether_hdr *)->ether_type ==
			    RTE_BE16(RTE_ETHER_TYPE_IPV4)) {
				first_len = rte_pktmbuf_data_len(m);
				memcpy(first, rte_pktmbuf_mtod(m, void *), first_len);
			}
			line_len = 0;
			parse_ether(m, 0, 0);
			printf("#%-2u len=%-3u %s\n", n, rte_pktmbuf_pkt_len(m), line);
			print_ptype(m);
			rte_pktmbuf_free(m);
		}
	}
	printf("parsed %u frames\n", n);

	if (first_len > 34)
		segment_demo(pool, first, first_len, 20);

	rte_eth_dev_stop(0);
	rte_eth_dev_close(0);
	rte_eal_cleanup();
	return 0;
}

"""Chapter 10 test traffic, with no external dependencies.

    python3 -I gen_pcaps.py            # writes mixed.pcap, in.pcap, empty.pcap

mixed.pcap : 14 hand-made frames that exercise every branch of parse_pcap.c
             (IPv4/UDP, TCP, ICMP, ARP, IPv6 with an extension header, VLAN,
             QinQ, VXLAN, IP options, fragments and three broken frames).
in.pcap    : 100 IPv4/UDP frames for the l2fwd run.
empty.pcap : a pcap header with no packets (an RX source that is always empty).
All checksums are correct unless a frame is deliberately broken.
"""
import struct

def csum(b):
    """RFC 1071 Internet checksum: one's-complement sum of 16-bit words."""
    if len(b) % 2:
        b += b'\0'
    s = sum(struct.unpack('!%dH' % (len(b) // 2), b))
    while s >> 16:
        s = (s & 0xffff) + (s >> 16)
    return (~s) & 0xffff

MAC_A = bytes.fromhex('020000000001')   # sender
MAC_B = bytes.fromhex('020000000002')   # receiver
BCAST = b'\xff' * 6

def eth(t, dst=MAC_B, src=MAC_A):
    return dst + src + struct.pack('!H', t)

def vlan(vid, inner_type, pcp=0):
    return struct.pack('!HH', (pcp << 13) | vid, inner_type)

def ip4(src, dst, proto, payload, ttl=64, ident=1, frag=0, opts=b'', ihl=None):
    hl = 20 + len(opts)
    if ihl is None:
        ihl = hl // 4
    h = struct.pack('!BBHHHBBH4s4s', 0x40 | ihl, 0, hl + len(payload), ident,
                    frag, ttl, proto, 0, bytes(src), bytes(dst)) + opts
    h = h[:10] + struct.pack('!H', csum(h)) + h[12:]
    return h + payload

def l4_cksum4(src, dst, proto, seg):
    ph = bytes(src) + bytes(dst) + struct.pack('!BBH', 0, proto, len(seg))
    c = csum(ph + seg)
    return 0xffff if (c == 0 and proto == 17) else c

def udp4(src, dst, sport, dport, payload):
    u = struct.pack('!HHHH', sport, dport, 8 + len(payload), 0) + payload
    c = l4_cksum4(src, dst, 17, u)
    return u[:6] + struct.pack('!H', c) + u[8:]

def tcp4(src, dst, sport, dport, flags=0x02, payload=b''):
    t = struct.pack('!HHIIBBHHH', sport, dport, 1000, 0, 5 << 4, flags, 65535, 0, 0) + payload
    c = l4_cksum4(src, dst, 6, t)
    return t[:16] + struct.pack('!H', c) + t[18:]

def icmp_echo(ident, seq, payload):
    i = struct.pack('!BBHHH', 8, 0, 0, ident, seq) + payload
    return i[:2] + struct.pack('!H', csum(i)) + i[4:]

def ip6(src, dst, nh, payload, tc=0, flow=0, hlim=64):
    vtc = (6 << 28) | (tc << 20) | flow
    return struct.pack('!IHBB', vtc, len(payload), nh, hlim) + src + dst + payload

def udp6(src, dst, sport, dport, payload):
    u = struct.pack('!HHHH', sport, dport, 8 + len(payload), 0) + payload
    ph = src + dst + struct.pack('!IxxxB', len(u), 17)
    c = csum(ph + u) or 0xffff
    return u[:6] + struct.pack('!H', c) + u[8:]

8Packet types: rte_net_get_ptype()

Many NICs classify packets in hardware and report the result in m->packet_type (ch7), so your code can branch on "IPv4/UDP" without parsing. The value is a 32-bit word of seven 4-bit fields: L2, L3, L4, tunnel, inner L2, inner L3, inner L4, with names RTE_PTYPE_* in lib/mbuf/rte_mbuf_ptype.h. Virtual devices like net_pcap, net_ring and net_null report nothing, so DPDK has a software classifier: rte_net_get_ptype(m, &hdr_lens, layers) in lib/net/rte_net.h. It returns the ptype and fills struct rte_net_hdr_lens (l2_len, l3_len, l4_len, tunnel_len, inner_l2_len...). layers says how deep to go (RTE_PTYPE_ALL_MASK, or e.g. RTE_PTYPE_L2_MASK | RTE_PTYPE_L3_MASK); rte_get_ptype_name() turns the value into text. l3fwd's --parse-ptype option (ch18) and GRO (ch19) depend on it.

  • It has bugs too. For plain IPv4/ICMP (#3) DPDK 26.11 returns 0x03000011, L2_ETHER L3_IPV4 INNER_L4_FRAG: "inner" bits without any tunnel. Reading lib/net/rte_net.c explains it: ICMP is not in its L4 table, so the code falls through to the tunnel/inner section with proto = 1, which happens to equal RTE_VXLAN_GPE_TYPE_IPV4; it then decodes the ICMP message as an inner IPv4 header. parse_pcap detects the inconsistency and re-asks for the outer layers only, which gives the sane L2_ETHER L3_IPV4. Treat library output as data to sanity-check, especially for protocols it does not list (it handles Ether/VLAN/QinQ/MPLS, IPv4/IPv6, TCP/UDP/SCTP and GRE, NVGRE, VXLAN, VXLAN-GPE, GENEVE, GTP-C/GTP-U and IP-in-IP tunnels).

VLAN and QinQ insertion

To add a tag to an existing frame you need 4 more bytes in front of it. Thanks to the mbuf headroom (128 bytes by default, ch7) that does not require copying the frame: rte_vlan_insert(&m) prepends 4 bytes, moves the two MAC addresses 4 bytes to the front, writes TPID 0x8100 and the TCI it takes from m->vlan_tci, and adds 4 to m->l2_len. It refuses (-EINVAL) on a shared or indirect mbuf and returns -ENOSPC without headroom. New in 26.11, rte_vlan_insert_tpid(&m, tpid) does the same with any TPID, so QinQ is two calls: insert the inner C-tag first, then the outer S-tag with 0x88a8. It is marked __rte_experimental, so you need -DALLOW_EXPERIMENTAL_API (section 10 shows the warning you get otherwise). rte_vlan_strip(m) is the inverse: it moves the tag into m->vlan_tci and sets RTE_MBUF_F_RX_VLAN_STRIPPED, what a NIC with VLAN-strip offload does on receive.

The Ethernet CRC

The 4-byte frame check sequence at the end of every Ethernet frame is a CRC32 computed and stripped by the NIC, so you rarely see it. When you do need one (software that emulates a NIC, a protocol that carries its own CRC, or eCPRI), lib/net/rte_net_crc.h computes CRC32-Ethernet and CRC16-CCITT with scalar, SSE4.2/PCLMULQDQ, AVX-512/VPCLMULQDQ or NEON code. Since 25.03 the API is context based: struct rte_net_crc *c = rte_net_crc_set_alg(RTE_NET_CRC_AVX512, RTE_NET_CRC32_ETH) picks the best implementation not above what you asked for and what the CPU and --force-max-simd-bitwidth allow; rte_net_crc_calc(c, data, len) computes; rte_net_crc_free(c) releases. build_packets computes every frame's CRC with both the scalar and the AVX-512 context, checks they agree, and verify.py compares them with Python's zlib.crc32, which uses the same polynomial.

Your own headers: __rte_packed_begin / __rte_packed_end

Sooner or later you parse a protocol lib/net does not have. Our toy tunnel header is 8 bytes: version, flags, a 32-bit session id at offset 2, and a 16-bit sequence number. Written as a normal struct, the compiler aligns session to 4 and pads the struct to 12 bytes, which no longer matches the wire. You have to pack it. The last command shows the other 26.11 build gotcha of this chapter: rte_vlan_insert_tpid() is experimental, and without -DALLOW_EXPERIMENTAL_API you get a "deprecated" warning (an error with -Werror).

A packed struct tells the compiler that members may be unaligned, so t->session = x is always safe. Taking the address of a packed member and using it as a plain uint32_t * is not (gcc warns with -Waddress-of-packed-member): on strict-alignment CPUs it can trap, and the compiler may assume alignment. For such pointers DPDK provides unaligned_uint16_t, unaligned_uint32_t and unaligned_uint64_t, which in 26.11 really have alignment 1 on every architecture (before, they were plain typedefs on x86). memcpy() into a local variable is the other safe choice; compilers turn a 4-byte memcpy into one load.

The TX buffer (struct rte_eth_dev_tx_buffer, lib/ethdev/rte_ethdev.h) exists because rte_eth_tx_burst() is expensive per call (ch8): a frame-at-a-time forwarder would pay that cost 32 times per received burst. rte_eth_tx_buffer(port, queue, buf, m) just stores the pointer and, when the buffer reaches its size, calls rte_eth_tx_burst() for all of them and returns how many it sent. Frames the NIC does not accept go to the error callback: by default they are freed; rte_eth_tx_buffer_count_callback also counts them. The drain timer covers the other case: with light traffic a buffer might never fill, so every BURST_TX_DRAIN_US (100 µs) the loop calls rte_eth_tx_buffer_flush() on every port. The timer is just a TSC comparison (rte_rdtsc(), ch3), no system call.

mini_l2fwd.c: the core loop on net_ring

mini_l2fwd.c keeps only l2fwd's data path: two ports, one lcore, a TX buffer per port with the counting error callback, the TSC drain timer, and per-port counters that separate full flushes from timer flushes. /* l2fwd_mac_updating(), written with struct copies instead of a uint64 store */
static inline void
rewrite_macs(struct rte_mbuf *m, uint16_t out_port)
{
	struct rte_ether_hdr *eth = rte_pktmbuf_mtod(m, struct rte_ether_hdr *);
	struct rte_ether_addr dst = {{0x02, 0, 0, 0, 0, (uint8_t)out_port}};

	rte_ether_addr_copy(&dst, &eth->dst_addr);
	rte_ether_addr_copy(&port_mac[out_port], &eth->src_addr);
}

/* Inject n IPv4/UDP frames by transmitting them on port 0 (loops to RX 0). */
static unsigned int
inject(struct rte_mempool *pool, unsigned int n)
{
	unsigned int i, done = 0;

	for (i = 0; i < n; i++) {
		struct rte_mbuf *m = rte_pktmbuf_alloc(pool);
		struct rte_ether_hdr *eth;
		struct rte_ipv4_hdr *ip;
		struct rte_udp_hdr *udp;
		uint16_t len = sizeof(*eth) + sizeof(*ip) + sizeof(*udp) + 18;

		if (m == NULL)
			break;
		eth = (struct rte_ether_hdr *)rte_pktmbuf_append(m, len);
		memset(eth, 0, len);
		ip = (struct rte_ipv4_hdr *)(eth + 1);
		udp = (struct rte_udp_hdr *)(ip + 1);
		rte_eth_random_addr(eth->src_addr.addr_bytes); /* some sender */
		eth->dst_addr = port_mac[0];
		eth->ether_type = RTE_BE16(RTE_ETHER_TYPE_IPV4);
		ip->version_ihl = RTE_IPV4_VHL_DEF;
		ip->total_length = rte_cpu_to_be_16(len - sizeof(*eth));
		ip->time_to_live = 64;
		ip->next_proto_id = IPPROTO_UDP;
		ip->src_addr = RTE_BE32(RTE_IPV4(10, 10, 1, 1));
		ip->dst_addr = rte_cpu_to_be_32(RTE_IPV4(10, 10, 2, 1) + i);
		ip->hdr_checksum = rte_ipv4_cksum(ip);
		udp->src_port = rte_cpu_to_be_16(1000 + i);
		udp->dst_port = RTE_BE16(2000);
		udp->dgram_len = rte_cpu_to_be_16(sizeof(*udp) + 18);
		if (rte_eth_tx_burst(0, 0, &m, 1) == 1)
			done++;
		else
			rte_pktmbuf_free(m);
	}
	return done;
}

		/* 2. receive, rewrite, buffer */
		for (p = 0; p < NB_PORTS; p++) {
			uint16_t out = p ^ 1, nb, i;

			nb = rte_eth_rx_burst(p, 0, pkts, MAX_PKT_BURST);
			st[p].rx += nb;
			for (i = 0; i < nb; i++) {
				uint16_t sent;

				rewrite_macs(pkts[i], out);
				/* returns 0 while buffering, or the number sent
				 * when this frame filled the buffer */
				sent = rte_eth_tx_buffer(out, 0, txb[out], pkts[i]);
				if (sent) {
					st[out].tx += sent;
					st[out].flush_full++;
				}
			}
		}
	}

	print_stats("final");

	/* Look at one frame waiting in each loopback ring: MACs rewritten? */
	for (p = 0; p < NB_PORTS; p++) {
		uint16_t nb = rte_eth_rx_burst(p, 0, pkts, 1), i;

		if (nb == 1) {
			struct rte_ether_hdr *eth =
				rte_pktmbuf_mtod(pkts[0], struct rte_ether_hdr *);
			char s[RTE_ETHER_ADDR_FMT_SIZE], d[RTE_ETHER_ADDR_FMT_SIZE];

			rte_ether_format_addr(s, sizeof(s), &eth->src_addr);
			rte_ether_format_addr(d, sizeof(d), &eth->dst_addr);
			printf("frame waiting on port %u: src %s dst %s\n", p, s, d);
			rte_pktmbuf_free(pkts[0]);
		} else {
			printf("frame waiting on port %u: none\n", p);
		}
		/* The TX buffer OWNS its mbufs: free them or they leak. */
		for (i = 0; i < txb[p]->length; i++)
			rte_pktmbuf_free(txb[p]->pkts[i]);
		txb[p]->length = 0;
	}

	for (p = 0; p < NB_PORTS; p++) {
		rte_eth_dev_stop(p);
		rte_eth_dev_close(p);
		rte_free(txb[p]);
	}
	rte_eal_cleanup();
	return 0;
}

Run 1, 20 frames, timer off: port 0 received all 20, and all 20 are still sitting in port 1's TX buffer after a second. They will never leave. Run 2, same traffic with the 100 µs timer: about 10,000 timer flushes per second (one per period, as configured) and zero full flushes; each lap of 20 frames waits for the timer, which caps this little loop at about 200,000 frames per second. Run 3, 100 frames, timer off: now the RX bursts are always full, so buffers fill and every send is a full flush, and the loop runs as fast as the CPU can go (tens of millions of frames per second on this VM; this is a software loopback, not a NIC measurement, and the counts vary between runs). The net_ring ports have no MAC, and rte_eth_dev_default_mac_addr_set() returns -ENOTSUP (-95), so the program picks software MACs and you can see the rewrite in the "frame waiting" line.

Tip: the TX buffer owns its mbufs

When you stop, frames still in a TX buffer are yours to flush or free; mini_l2fwd frees them explicitly. l2fwd itself just exits. In an application that stops and restarts ports (ch12) that would leak mbufs every time.

Common pitfalls

  • Packets go to 2.0.10.10 / port 53255: a host-order value (RTE_IPV4(), a plain integer port) stored without rte_cpu_to_be_32/16(). Grep for assignments to *_addr and *_port.
  • Every checksum is wrong in a capture: you byte-swapped the result of rte_ipv4_cksum() or rte_ipv4_udptcp_cksum(). Store it as returned.
  • Checksum of 0x0000 after editing a header: you recomputed without zeroing hdr_checksum (or dgram_cksum) first. Zero it, or use rte_ipv4_cksum_simple() / an incremental update.
  • UDP checksum wrong after rewriting an IP address: the pseudo-header includes both addresses; update the L4 checksum too.
  • IPv6 L4 checksum fails only for some packets: those carry extension headers, and rte_ipv6_udptcp_cksum*() assumed there were none.
  • Crash or garbage on short frames: a header was dereferenced before checking the length. Use rte_pktmbuf_read() or compare against rte_pktmbuf_data_len() first, and never use pkt_len to justify a pointer into the first segment.
  • Trusting rte_net_get_ptype() as a validator: it does not check checksums or IHL, and in 26.11 it misclassifies IPv4/ICMP. Use it to dispatch, then validate.
  • UDP offset computed with sizeof(struct rte_ipv4_hdr): breaks on packets with IP options (frame #10). Use rte_ipv4_hdr_len().
  • Old code compiles but the header is 12 bytes: } __rte_packed; after 26.11 declares a variable. Switch to __rte_packed_begin/__rte_packed_end and add RTE_BUILD_BUG_ON(sizeof(...) != N).
  • "'rte_vlan_insert_tpid' is deprecated: Symbol is not yet part of stable ABI": experimental API; build with -DALLOW_EXPERIMENTAL_API.
  • Light traffic never leaves, or leaves late: a TX buffer without a drain timer, or a drain period too long for your latency budget.
  • Using the old names: RTE_IP_ICMP_ECHO_REQUEST/_REPLY were removed in 26.11; use RTE_ICMP_TYPE_ECHO_REQUEST/RTE_ICMP_TYPE_ECHO_REPLY. IPv6 addresses are struct rte_ipv6_addr, not uint8_t[16].

Summary
  • lib/net gives one packed, 2-byte-aligned struct per protocol header; parsing is placing them at the right offsets, building is filling them in fresh mbuf space.
  • Every multi-byte field is big-endian: rte_be_to_cpu_*() to read, rte_cpu_to_be_*() to write, RTE_BE16/32() for constants. RTE_IPV4() is host order. Checksums are the exception: store them as the library returns them.
  • The Internet checksum is a one's-complement sum, folded and inverted; a valid packet sums to 0xffff. UDP/TCP add a pseudo-header with the IP addresses. RFC 1624 updates it without re-summing.
  • 26.11: struct rte_ipv6_addr, RTE_IPV6(), vtc_flow masks instead of bitfields, RTE_ICMP_TYPE_ECHO_*, rte_vlan_insert_tpid() (experimental), __rte_packed_begin/__rte_packed_end (the old __rte_packed silently becomes a variable name), truly unaligned unaligned_uintNN_t.
  • Safe parsing: check before dereferencing, validate lengths, use protocol lengths, and use rte_pktmbuf_read() so headers split across segments work.
  • rte_net_get_ptype() classifies in software for vdevs, but it is not a validator and has blind spots (IPv4/ICMP in 26.11, IPv6 checksums with extension headers in the cksum helpers).
  • l2fwd = rx_burst, MAC rewrite, rte_eth_tx_buffer(), plus a TSC drain timer. Under load the buffer fills; at low load only the timer sends, and it bounds the extra latency.
