A B-tree of order 4 whose nodes live in slabs: blocks of four equal slots with one "free" bit per slot. Nodes name each other by a 32-bit handle (pool, slab, slot) and not by address. Insert and delete keys and watch slots fill, holes appear, and vacuum move nodes to give a slab back. Then press Static memory: all slabs are reserved before the first key, the allocator is frozen, and the tree runs in a footprint that cannot change until an insert is refused. Chapter text: README. Second page: the buddy allocator.
