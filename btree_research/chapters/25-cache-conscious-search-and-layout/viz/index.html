Inside a page the unit of cost is the 64-byte cache line, and every unpredictable if is a guess the CPU can get wrong. Watch five ways to find the same key and count the lines each one touches. Text and code: chapter 25 README.

1. One lookup, step by step

Each box is one cache line holding eight 8-byte keys. Pick an algorithm and a needle, then step. The answer is always the lower bound: the position of the first key that is not smaller than the needle. Tick Predict to be asked before each comparison.

2. The same lookup in all five

One small square per cache line of each algorithm's array; filled squares were read. Below it, the average over 1000 seeded random needles: these are the numbers the Zig and Rust programs print.

3. What prefetch changes

4095 keys, 1000 lookups. A line that is read without having been hinted is a miss the CPU has to sit through before it can even compute the next address. Prefetch does not reduce the lines read; it makes all but the first one start loading early.
