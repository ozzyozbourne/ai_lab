# Evaluations for AI: LLMs, Agents and RL Environments

A ten-chapter HTML book on evaluating AI systems: benchmarks and metrics, eval datasets and contamination,
LLM-as-a-judge and human evaluation, statistics, AI agents, RL environments (rewards, verifiers, reward hacking),
safety and red-teaming, tooling and production/online/RAG evaluation, and an end-to-end capstone.
It was written in November 2026 from research dossiers that checked each source (arXiv papers, GitHub repositories,
practitioner articles). They are kept in `research/`.

## Reading

Open `index.html` in a browser. Everything is local (no CDN, no web fonts), so it works straight from disk.
On a chapter page, press `t` to toggle the sidebar, and use the moon/sun button for dark mode.

## Running the code

Every chapter has runnable programs in `code/chNN/`. They need Python 3.10 or newer and NumPy, and nothing else:
no API keys and no network. Models, judges, agents and users are mocked with seeded random generators,
so the numbers printed match the book.

```bash
python3 -m pip install numpy
python3 code/ch01/mini_harness.py   # one example
python3 code/run_all.py             # every example, with a pass/fail table
python3 code/run_all.py ch06 ch07   # selected chapters
```

## Layout

```
index.html, 01-...html .. 10-...html, references.html
assets/book.css, assets/book.js     shared style and runtime (TOC, prev/next, copy buttons, highlighting)
assets/chapter-template.html        every HTML convention used by the chapters
code/chNN/                          runnable examples per chapter
code/run_all.py                     runs all examples
tools/build_references.py           regenerates references.html from the chapters' Sources sections
tools/check_links.py                parses every HTML page and checks local links, anchors and the nav manifest
research/                           source dossiers used to write the book
plan.md                             the book plan and the writers' style guide
```

## Maintaining the book

Navigation (sidebar, prev/next links) is generated by `assets/book.js` from the chapter manifest at the top of that file,
so a new or renamed chapter must be added there and in `index.html`. After editing a chapter:

```bash
python3 tools/build_references.py   # rebuild references.html (sources are merged by arXiv id, GitHub repo, DOI or URL)
python3 tools/check_links.py        # HTML structure, duplicate ids, local hrefs/srcs and #anchors; exit 1 on problems
python3 code/run_all.py             # every example still runs
```

The book is about 200,000 words: chapters run from about 15,000 to 26,000 words each, with 119 runnable example
programs plus two small pytest files (`code/ch01/test_regression_gate.py`, `code/ch08/test_toy_agentdojo.py`).

Tool facts (repo locations, versions, deprecations) are as of November 2026.
