An interactive book

Data-Oriented Design in Rust, Zig and Odin

The CPU never reads a single byte: it pulls in a 64-byte cache line. This book is about arranging your data so that those bytes are the ones you need. Each idea comes with a figure you can poke, code in three languages that compiles, and benchmarks measured on a real machine.

Memory as rows of 4-byte cells, one 64-byte cache line per row. (The 3D view needs WebGL and the Three.js CDN.)

Contents

    How to read this book

    Read the chapters in order. Chapters 1–3 give you the vocabulary (the machine, cache lines, layout), 4–9 are the core techniques, 10 and 11 are projects that combine them, and 12 is about measuring, including when not to bother.

    • Figures are live. Use Play, Step, Back and Reset to move through them, and use the toggles under them. Every counter is computed by the figure's own model. With reduced motion turned on, figures don't animate and show their final state.
    • Predict before you reveal. Yellow "Predict first" boxes ask a question before a figure answers it.
    • Code tabs switch between Rust, Zig and Odin across the whole book, and your choice is remembered.
    • Callouts mark notes, pitfalls, version changes (e.g. "Changed in Zig 0.17"), and commands to try.
    • Numbers. Benchmarks come from the programs in code/, run on one cloud VM: an Intel Xeon Ice Lake-SP at 2.6 GHz, 2 cores × 2 threads, L1d 48 KiB, L2 1.25 MiB, and a 54 MiB L3 shared with other tenants (Chapter 2 measures only a few MiB of it as usable). The text calls this machine “this orb”. Your machine will give different numbers. The ratios and shapes are what matter. Numbers quoted from other people are labelled "cited".

    How to run the code

    Every chapter has a Rust package, a single-file Zig program, and an Odin package under code/chNN-<slug>/. They use only the standard library. The versions used are Rust 1.100 (edition 2024), Zig 0.17.1 and Odin dev-2026-11.

    Run one chapter in all three languages, or everything in quick mode:

    cd code
cargo run --release -p chNN_slug -- --quick             # Rust (one Cargo workspace; package = dir name with _)
cd chNN-slug/zig && zig run -O fast main.zig -- --quick
cd .. && odin run odin -o:speed -vet -strict-style -- --quick
cd .. && ./run_all.sh                                     # lint + build + run all, prints a table

    Leave out --quick for full-size runs, or pass a size: -- 1000000. ./bench_all.sh does the serial, pinned benchmark pass that produces the charts.

    Zig 0.17 spells the release mode -O fast (formerly -O ReleaseFast, which is still accepted). Code in this book follows 0.17.1 idioms: main(init: std.process.Init), std.Io clocks, and unmanaged containers.

    To read offline, open index.html directly (double-click it). Everything except the 3D picture above is local.
