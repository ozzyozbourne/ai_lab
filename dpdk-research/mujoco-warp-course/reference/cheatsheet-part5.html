    1Part V at a glance: one solve per world

    Per world, MJWarp minimizes a convex function of the acceleration: min_a ½(a - a_s)ᵀM(a - a_s) + Σ_i s_i(J_i a - aref_i). It is not an LCP: there is one minimizer, and at the optimum M q̈ = τ_smooth + Jᵀf exactly (Ch 19 §3).

    Ch 19 §4, §9, §10

    From solref/solimp to D and aref

    # _contact_kbimp / _efc_row (constraint.py)
k = 1 / (dmax**2 * timeconst**2 * dampratio**2)
b = 2 / (dmax * timeconst)
timeconst = max(timeconst, 2 * h)     # refsafe, unless DisableBit.REFSAFE
d = impedance(pos, solimp)            # sigmoid in [dmin, dmax]
D = d / ((1 - d) * w)                 # efc.D
aref = -b * vel - k * d * pos         # efc.aref

    impratio is stored as opt.impratio_invsqrt (Ch 19 §8).

    Storage of J

    • Dense (nworld, njmax_pad, nv_pad) for nv ≤ 32 under jacobian=auto.
    • Sparse CSR (nworld, 1, njmax_nnz) + J_rownnz/J_rowadr/J_colind above; forced dense is refused above nv 60.
    • Use contact.efc_address and efc.id, never assume an order (Ch 19 §7, §6).

    CG vs Newton

    • CG: preconditioned with the factored M, Polak-Ribière β clamped at 0; many cheap iterations; benefits most from warmstart.
    • Newton: factors H = M + JᵀDJ per world (one tile up to nv 48, blocked 16×16 tiles up to 96, sparse beyond); few expensive iterations. Pyramidal Newton updates H by rank-1 terms for flipped rows.
    • Only QUADRATIC rows add to the Hessian.

    mjw.step(m, d)
niter = d.solver_niter.numpy()        # (nworld,)
print(niter.max(), np.percentile(niter, 95))
hit = d.overflow.numpy() & int(mjw.OverflowType.ITERATIONS)

    The loop waits for the slowest world: cap iterations near the converged count, not below it (Ch 20 §11, §9).

    States

    • tree_island: island id per tree, -1 for trees with no rows.
    • tree_asleep: -11 .. -1 awake countdown; ≥ 0 next tree in a sleep cycle. Ten still steps and a whole island at -1 make a cycle; qvel, qacc become exactly 0.
    • Actuated trees compile to AUTO_NEVER: a robot never sleeps.

    Ch 21 §5, §4

    Waking and starting asleep

    • User changes, contact with awake trees, active equalities and tendons wake a tree; waking one wakes its cycle (Ch 21 §6).
    • Start asleep: write tree_asleep = arange(ntree) into the host MjData before put_data (§7).
    • mjw.island(m, d) runs discovery on demand.
    • Pays for mostly resting clutter, not always-moving robots; measure on the GPU (§10).

    5The determinism matrix

    Three sources of run-to-run noise on a GPU: contact slots (atomic_add(nacon_out, 0, 1)), efc rows (atomic_add(nefc_out, worldid, k)) and float atomics. In 4.0.1 only ATOMICS does anything: CONTACTS and CONSTRAINT call stubs whose body is pass.

    m.opt.deterministic = mjw.DeterminismType.ATOMICS   # 4; True means ALL (7)
m.opt.deterministic &= ~mjw.DeterminismType.ATOMICS  # stored as a plain int
# mjwarp-testspeed model.xml -o "opt.deterministic=ATOMICS"   (measure the cost)

    6Soft bodies and the DISCRETE integrator

    What a flex is

    • Vertices (point masses on 3-slider bodies), edges and simplex elements; flexcomp builds them; smooth.flex computes flexvert_xpos, flexedge_length, flexedge_J (Ch 23 §1).
    • Shape kept by edge equalities (rows), elasticity (passive forces) or dim-1 edge springs; cloth elasticity needs elastic2d (§2).
    • Flex contacts are found after rigid ones; a flex side has geom == -1 (§5).

    DISCRETE

    Solves (M + hD + h²K) a = f - hKv: eff_build → eff_shift → eff_actuation + regularize_constraint → eff_solve (PCG) → the constraint solve in the same metric. Stable for stiff flexes, dissipative, about 3-4x Euler per step in the CPU run (Ch 23 §7, Ch 19 §11).

    Refused by 4.0.1

    • hfield, SDF or rigid flexes; quadratic interpolation;
    • self-collision and passive contact of interpolated flexes;
    • flex edge equalities with sleep;
    • SNH or passive contact without DISCRETE; elasticity under IMPLICIT/IMPLICITFAST;
    • edge stiffness or noslip under DISCRETE; Newton with general attachments.

    Errors come from put_model or forward.py::check_discrete (Ch 23 §8).

    7Pitfalls

    • Row overflow does not raise: nefc keeps counting past njmax, rows are dropped, NEFC is set (Ch 19 §6).
    • Row order means nothing: read rows through efc.id / contact.efc_address.
    • Lowering iterations below convergence changes the answer; check the ITERATIONS bit.
    • Changing ls_iterations, solver or cone compiles new kernels; graphs need a recapture.
    • 4.0.1 never picks the better start between warmstart and qacc_smooth (Ch 20 §12).
    • Elliptic cones creep under soft friction; noslip_iterations removes it at a cost (Ch 20 §13).
    • island="disable" with sleep silently disables sleep.
    • deterministic=True is ATOMICS in practice; it costs record buffers and sorts: debugging and regression tests only (Ch 22 §8).
