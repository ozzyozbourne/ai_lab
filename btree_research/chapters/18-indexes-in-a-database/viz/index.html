A B+tree maps a key to a value. A database table needs more: rows have several columns, and you want to find them by more than one of them. This page runs the same query on the same table stored in two ways: the rows inside the primary tree (clustered, as Turso and SQLite do), or the rows in a heap with every index pointing at an address (as Postgres does). Watch what an index entry points at, and what it costs to follow it. Text: chapter 18.
