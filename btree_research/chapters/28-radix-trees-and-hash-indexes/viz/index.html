A radix tree does not compare keys. It uses the key's bytes, one after another, as directions. The adaptive radix tree keeps that cheap: a node starts with room for 4 children and is copied into a larger layout (16, 48, 256) only when it fills up, and a run of bytes without any branching is stored once, as a prefix.
