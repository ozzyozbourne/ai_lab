pass@k = 1 − C(n − c, k)C(n, k) (N.1) where n is the number of samples drawn per problem, c the number that pass, and k ≤ n.

With n = 10 samples and c = 3 correct: pass@3 = 1 − C(7,3)/C(10,3) = 1 − 35/120 = 0.708. Every number in a worked example must be reproduced by a script in code/chNN/; say which one.

"""Unbiased pass@k (Chen et al., 2021)."""
import math


def pass_at_k(n: int, c: int, k: int) -> float:
    """Probability that at least one of k samples (drawn without replacement from n) passes."""
    if n - c < k:
        return 1.0
    return 1.0 - math.comb(n - c, k) / math.comb(n, k)


if __name__ == "__main__":
    print(f"pass@3 = {pass_at_k(10, 3, 3):.3f}")  # 0.708
