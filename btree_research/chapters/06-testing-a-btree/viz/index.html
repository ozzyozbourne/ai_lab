A fuzzer feeds the same random operations to a B-tree and to a sorted list that is obviously correct, and stops at the first step where the two disagree or the tree breaks one of its own rules. Pick a broken tree and watch it get caught, then shrink the failing run to a few steps.

This page belongs to Chapter 06: Testing a B-tree. The operation stream is on the left; the tree under test and the oracle are on the right. After every step the page runs the three checks of the chapter's fuzzer: is the answer the same, does validate() pass, and (every 16 steps and at the end) is a full scan of the tree equal to the oracle. Everything is computed in your browser by a JavaScript port of the chapter's Zig and Rust code: the same seeds give the same operations, the same failing step and the same reproducer that zig build run prints.

The three broken trees

VariantThe one-line changeWhat it doesWhich check sees it
split_wrong_valueinsert: a split sends the median key up with its left neighbour's value The shape stays perfect; one key has the wrong value.Only the comparison with the oracle. validate() is silent.
merge_leaks_nodedelete: a merge never returns the emptied node to the pool Every answer stays right; one node is allocated but unreachable.Only validate(): the pool counts one more live node than the tree can reach.
borrow_forgets_childdelete: a borrow between interior nodes moves the key but not the child An interior node has a key more than it has children for; a whole subtree is lost.validate(): MissingChild. Needs a tree of height 3, so fewer seeds reach it.

Suggested experiments: for each variant, press Shortest failing run, step to the end, then press Minimise and step through the reproducer by hand. Tick Predict to be asked which check will catch the bug before the failing step is shown. Replay seed 3 (four possible keys) and seed 28 (64 keys) on the correct tree to see how different two swarm cases are. Replay a seed that does not catch the third variant (seed 3 is one) to see a broken tree pass a test that never builds a third level.
