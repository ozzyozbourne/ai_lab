    1One launch, many worlds

    A kernel launch with dim=nworld starts one thread per world. Every lane below runs the same code on its own world's data. Inline math uses KaTeX: E = \tfrac12 m v^2 + m g z, and display math:

    q_{t+h} = q_t + h\,\dot q_{t+h}

    Note

    Use .note for neutral information.

    Tip

    Use .tip for a shortcut or good habit.

    Pitfall

    nconmax is per world; naconmax is the total over all worlds (io.py docstrings). Class .warning or .pitfall.

    Recall from Ch 2

    MuJoCo quats are (w,x,y,z); Ch 2 §3.

    Going deeper: what does the launch compile to?

    Collapsible expert-only material lives in <details class="callout deeper">. Warp JIT-compiles each Python kernel to CUDA C++ (or C++ for the CPU device) and caches the binary.

    3Stepper: an algorithm, one state at a time

    Rule A: algorithm animations use the stepper. This one walks through write_contact: each narrowphase thread reserves a slot in the shared contact pool with wp.atomic_add, and a contact whose slot index is at or past naconmax is dropped.

    Reserving contact slots

    collision_core.py::write_contactIllustrative order
    active = dist_in < margin_in
detected = dist_in < margin_in + gap_in
if not detected: return 0
cid = wp.atomic_add(nacon_out, 0, 1)
if cid < naconmax_in:
    contact_pos_out[cid] = pos_in
    contact_worldid_out[cid] = worldid_in
    return int(active)
return 0

    6Exercises

    Exercise 0.1: landing time

    Auto-checked

    Predict when a ball dropped from 1 m touches the floor (radius 0.1 m) and assert your prediction against the simulation within 5%.

    t_pred = ...  # your formula
assert abs(t_sim - t_pred) / t_pred < 0.05
    Show solution

    Free fall over 0.9 m: t = \sqrt{2 \cdot 0.9 / 9.81} \approx 0.428\,\mathrm{s}.

    t_pred = (2 * 0.9 / 9.81) ** 0.5
