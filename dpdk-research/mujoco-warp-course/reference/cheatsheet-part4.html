    1Part IV at a glance: the funnel

    Collision narrows all geom pairs down to contacts in three stages. The first runs once in put_model; the other two run every step, for every world, and share buffers of size naconmax.

    2Filters: static and per step

    Static masks in put_model

    • (contype1 & conaffinity2) | (contype2 & conaffinity1) != 0 (either direction).
    • Same weld body; both weld bodies dof-less.
    • Parent-child (both not world) unless DisableBit.FILTERPARENT.
    • <contact><exclude> body pairs.

    m.nxn_pairid column 0: -2 never, -1 default materials, ≥ 0 explicit <pair> id; column 1: collision-sensor id or -1 (Ch 15 §3).

    Bounding-volume filter (m.opt.broadphase_filter)

    BitValueTest
    PLANE1other centre within rbound + margins of the plane
    SPHERE2|x2 - x1|² ≤ (r1 + r2 + m1 + m2)²
    AABB4world AABBs of the rotated local boxes
    OBB86 face-normal separating axes

    Default 11 = PLANE|SPHERE|OBB, baked in with wp.static. Planes (rbound == 0) only see the plane test; margins are margin + gap (Ch 15 §4).

    Broadphase choice (put_model)

    if npairs_listed < 250_000:   opt.broadphase = NXN
elif mjm.ngeom < 1000:        opt.broadphase = SAP_TILE
else:                         opt.broadphase = SAP_SEGMENTED
m.opt.broadphase = mjw.BroadphaseType.SAP_TILE  # switch any time (new kernels once)

    Same candidates with the default filter, except collision-sensor pairs SAP's sweep does not reach. SAP allocates scratch per call and cannot sit inside a graph conditional (Ch 15 §7, §9).

    Skipped every step

    • asleep + asleep and asleep + static pairs (Part V sleep).
    • missing per-world meshes; NaN geom centres (Ch 15 §8).

    NXN: dim=(nworld, nnxn_geom_pair_filtered), atomic compaction. SAP: oblique-axis projection, per-world sort, nsweep = 5·nworld·ngeom threads (§5, §6).

    3The dispatch table

    collision_driver.py::MJ_COLLISION_TABLE, keyed by the ordered pair (type1 ≤ type2). P = primitive collider, C = convex path (GJK/EPA, or heightfield prisms when one side is HFIELD), · = never collides. Printed by Ch 16's Example 16.1 from the 4.0.1 wheel.

    planehfieldspherecapsuleellipsoidcylinderboxmesh
    plane··PPPPPP
    hfield··CCCCCC
    spherePCPPCPPC
    capsulePCPPCCPC
    ellipsoidPCCCCCCC
    cylinderPCPCCCCC
    boxPCPPCCC*C
    meshPCCCCCCC

    Counts and exceptions

    • 12 PRIMITIVE, 21 CONVEX, 3 missing (plane-plane, plane-hfield, hfield-hfield).
    • * box-box is CONVEX by default; DisableBit.NATIVECCD flips only this cell to PRIMITIVE (box_box, up to 8 clipped vertices).
    • SDF is not in the table: SDF pairs go to sdf_narrowphase.
    • Flex: plane, sphere, capsule, box, cylinder → PRIMITIVE; mesh, ellipsoid → CONVEX; no hfield (MJ_FLEX_COLLISION_TABLE).

    Ch 16 §1

    GeomType values

    PLANE 0, HFIELD 1, SPHERE 2, CAPSULE 3, ELLIPSOID 4, CYLINDER 5, BOX 6, MESH 7, SDF 8, FLEX 105; Warp-only TRIANGLE 999.

    _add_geom_pair orders every candidate by type, so geom[0] is the lower type and the normal points from geom[0] to geom[1] (Ch 16 §2).

    How it launches

    • Primitive: one fused launch over pool slots (dim = d.naconmax), a static if-chain of the type pairs the model has; lanes can diverge.
    • Convex: one kernel per present type pair, grid-stride (_ccd_grid_size); heightfield pairs one thread per slot.
    • Changing which geom types exist recompiles; sizes, poses, materials do not (Ch 16 §4).

    4Contact rules and materials

    write_contact

    • detected if dist < margin + gap (strict, float32); active (a constraint) if dist < margin, or in the gap with adhesion (then condim 1).
    • pos is midway between the surfaces; geomcollisionid numbers a pair's contacts.
    • Slot from wp.atomic_add(nacon_out, 0, 1), then contact_worldid_out[cid] = worldid.

    Ch 16 §5

    Material mixing (no explicit pair)

    • Higher priority wins; otherwise max condim, element-wise max friction, solmix-weighted solref/solimp, summed adhesion; friction clamped to mjMINMU.
    • 4.0.1 detail: a direct solref on either side gives the element-wise min.
    • An explicit <pair> uses its own margin, gap, friction, condim, solref, solimp.

    Ch 16 §6

    Collider facts

    • Capsule-capsule gives 2 contacts only when parallel within the 1e-8 test (about 0.006°).
    • Plane-box keeps every corner inside the margin; box-box (convex) gives up to 4 via multi-contact.
    • Surface velocity: a batched geom field → contact.surfacevel → friction rows' efc.Jqvel (conveyors, Ch 16 §9).
    • Core colliders are @wp.funcs callable from your kernels (private API, §10).

    5The convex path: GJK, EPA, multi-contact

    Pipeline

    support functions → GJK → (EPA) → (multi-contact) → write_contact. No MPR. Minkowski support: support(A, d) - support(B, -d); the origin is inside exactly when the shapes overlap (Ch 17 §2).

    • GJK: signed-volume sub-algorithm, stops on the Frank-Wolfe gap (§3).
    • gjk_phase shrinks spheres/capsules to their cores and inflates back; only deep penetration needs EPA (§4).
    • EPA: horizons longer than 24 set EPA_HORIZON (§5).
    • Multi-contact: Sutherland-Hodgman clipping, max-area 4 points; always on for box-box, else DisableBit.MULTICCD controls it (§6).

    Knobs

    OptionDefaultKind

    Meshes collide as their convex hulls (hill-climbing on the hull graph): decompose non-convex meshes (Ch 17 §8, scratch: §7).

    6Heightfields and SDFs

    Heightfield pairs (CONVEX)

    _hfield_filter → sub-grid → two prisms per cell → GJK/EPA per prism → at most 50 candidates → at most 4 contacts (deepest, farthest, farthest from the line, farthest from the edges) (Ch 18 §2, §3).

    HFIELD bit: the 50-slot buffer filled with prisms left; use coarser grids under big geoms. Defaults grow with nv when a heightfield exists: measure and pass explicit sizes (§4, §5).

    SDF pairs

    sdf_initpoints Halton starts in the AABB intersection, sdf_iterations Armijo steps; one contact per converged start (Ch 18 §7). Mesh SDFs are octree samples: less exact, costlier per query (§11).

    # top of a FRESH process, before the first MJWarp call (private API)
from mujoco_warp.test_data.collision_sdf.utils import register_sdf_plugins
sdf_types = register_sdf_plugins(mjw)   # nut, bolt, torus, gear

    A late patch is silently ignored (Ch 18 §9); your own SDF: §10.

    7Pitfalls

    • contype/conaffinity is symmetric-OR: a (2, 1) geom touches a (1, 1) geom.
    • Overflow in collision is silent: BROADPHASE / NARROWPHASE light up in every world; CCD, HFIELD and EPA_HORIZON have their own bits (Part II sheet).
    • Adding a geom type recompiles the fused narrowphase; changing sizes does not.
    • Comparing contact counts with MuJoCo C is misleading for heightfields; compare physics (Ch 18 §3).
    • Non-convex meshes collide as hulls: decompose them.
    • SDF plugins registered too late are ignored without an error.
    • Flex + heightfield is refused in 4.0.1 (Part V sheet).
    • SAP inside a graph conditional does not work: it allocates scratch per call.
