Chapter 03

The EAL: Lcores, Launching Work, Threads, Logging and Time

Every DPDK program starts with rte_eal_init(). After this chapter you will know what that call sets up, how to choose which CPUs your code runs on, how to run a function on another core and collect its result, which threads your process really has, how to log the DPDK way, how to read the clock in a few nanoseconds, and how to stop cleanly.

1What the EAL is

The Environment Abstraction Layer (EAL) is the part of DPDK that sits between your program and the operating system. Every other library (rings, mempools, ethdev, crypto) uses the EAL instead of calling Linux directly. That is how the same DPDK code runs on Linux, FreeBSD and Windows, on x86, Arm and POWER.

The EAL gives you seven services. You will meet all of them in this course; this chapter covers the first, fifth, sixth and seventh in depth, and the rest at the level you need to read the start-up log.

  1. Cores. It discovers the CPUs and NUMA nodes, creates one thread per lcore you asked for, pins each thread to its CPUs and lets you launch functions on them.
  2. Memory. It reserves large, pinned, DMA-able memory (hugepages) and runs a heap on it. That is ch4.
  3. Devices. It scans buses (PCI, vdev, ...) and probes drivers for the devices it finds. Devargs and virtual devices are ch9.
  4. Interrupts and alarms. A background thread waits on file descriptors (link-state changes, timers) with epoll. Alarms and timers are ch11.
  5. Time. It measures the CPU's time stamp counter (TSC) once, so you can read time cheaply afterwards.
  6. Multi-process. A shared configuration file and a UNIX socket let a second process attach to the first. That is ch16.
  7. Logging. Since DPDK 23.11 this lives in its own library, lib/log, but the EAL sets it up from your command line.

2What rte_eal_init() does, step by step

int rte_eal_init(int argc, char **argv) (declared in lib/eal/include/rte_eal.h, implemented for Linux in lib/eal/linux/eal.c) does all the set-up in one call. It returns the number of command-line arguments it consumed, or -1 with rte_errno set. You can call it only once per process: a second call fails with EALREADY.

On this VM the CPU does not report its TSC frequency in a way EAL trusts, so get_tsc_freq() in lib/eal/linux/eal_timer.c sleeps 100 ms and compares the TSC with CLOCK_MONOTONIC_RAW. Note: the order is designed

Logging is set up first so that every later phase can report errors. The multi-process socket is created before the bus scan so a secondary process can ask the primary which virtual devices exist. Virtual devices are probed last so that composite drivers (bonding, failsafe) can refer to physical ports that are already probed. The full order with function names is in rte_eal_init() in lib/eal/linux/eal.c.

4Lcores are not CPUs

An lcore (logical core) is a DPDK thread identity: a small number from 0 to RTE_MAX_LCORE - 1 (128 in this build). Each lcore is one EAL thread with a cpuset, the set of CPUs it is allowed to run on. A CPU is what Linux calls a CPU: a hardware thread numbered in /proc/cpuinfo. Most of the time lcore N runs on CPU N, and that is why the two words get mixed up. They do not have to match:

  • -l 0-3: lcores 0, 1, 2, 3, each pinned to the CPU with the same number. Lists and ranges mix: -l 0,2-3.
  • --lcores='0,(1-3)@(1,2)': lcore 0 on CPU 0; lcores 1, 2 and 3 all share the cpuset {1, 2}. Four threads, two CPUs: the kernel time-slices them. The @ separates lcore ids (left) from CPUs (right); parentheses make groups. In 26.11 -l accepts the same syntax.
  • --lcores='(0,6)': a group without @ means "these lcores, each on all these CPUs".
  • -l 2-3 -R: remap lcore ids so they start at 0: lcore 0 runs on CPU 2 and lcore 1 on CPU 3. Useful when your code has arrays indexed by lcore id.
  • --main-lcore 3: by default the lowest lcore id is the main lcore, the one that runs main(). This option picks another one. It must be one of the enabled lcores.

The EAL also starts control threads (interrupt handling, multi-process messages, telemetry). They are not lcores. They run on the CPUs that the process was allowed to use at start-up minus every CPU in any lcore's cpuset. If that leaves nothing, they share the main lcore's CPU (compute_ctrl_threads_cpuset() in lib/eal/common/eal_common_options.c). The debug line Control threads will use cores: ... tells you which.

    6Launching work on lcores

    After init, every worker lcore thread exists but does nothing: it is asleep, blocked in read() on a pipe. To give it work you call (from lib/eal/include/rte_launch.h):

    7The threads of a DPDK process

    A running DPDK process has three kinds of threads:

    • EAL threads (lcores): the main thread (it runs main() and is the main lcore) and one dpdk-worker<N> per worker lcore, each pinned to its cpuset.
    • Control threads: created by EAL or by you with rte_thread_create_control(). They are not lcores (rte_lcore_id() is -1) and run on the control-thread CPUs. EAL's own are dpdk-intr (interrupts and alarms), dpdk-mp-msg (multi-process messages) and dpdk-telemet-v2 (the telemetry socket, ch13).
    • Non-EAL threads: plain pthread_create() threads. They have no lcore id, so DPDK functions that need one (per-lcore mempool caches, rte_timer_manage()) do not work well in them. rte_thread_register() gives such a thread a free lcore id with role NON_EAL; rte_thread_unregister() gives it back. Registered threads do not work with multi-process.

    8Logging the DPDK way

    DPDK logging (lib/log/rte_log.h) has two filters. Each message has a level from 1 (EMERG) to 8 (DEBUG): 4 is ERR, 5 WARNING, 6 NOTICE, 7 INFO. Each message also belongs to a logtype, a dotted name such as lib.eal, lib.ethdev, pmd.net.null or, for applications, user.<something>. Each logtype has its own level, and there is one global level. A message is printed only if its level is at or below both (rte_log_can_log() in lib/log/log.c). The default output is stderr.

      9Time: the TSC, delays, and how to measure

      Every x86 core has a time stamp counter (TSC), a 64-bit register that counts at a fixed rate. On this machine the CPU flags constant_tsc and nonstop_tsc are set, so the rate does not change with CPU frequency or sleep states, and the counters of all cores agree. EAL measures the rate once at init. After that, reading the time is one instruction:

      • rte_rdtsc(): read the counter (lib/eal/x86/include/rte_cycles.h). The CPU may execute it a little earlier or later than the surrounding instructions.
      • rte_rdtsc_precise(): a full memory barrier (rte_mb()), then rte_rdtsc(). Use it at the start and end of a measured region, so earlier work cannot slip past the read.
      • rte_get_tsc_hz(): counts per second. Cycles to seconds: cycles / (double)rte_get_tsc_hz().
      • rte_get_timer_cycles() / rte_get_timer_hz(): the generic timer, which is the TSC unless DPDK was built with HPET support.
      • rte_delay_us_block(us) spins (100% CPU); rte_delay_us_sleep(us) sleeps in the kernel (nanosleep); rte_delay_us() and rte_delay_ms() spin by default.

      tsc_lab.c measures all of that. The core of it is a tiny benchmark harness that follows the recipe in the box below:

      /* One repetition: CALLS calls, timed with the TSC; returns ns per call. */
static double
one_rep(clock_fn fn, double ns_per_cycle)
{
	uint64_t acc = 0, t0, t1;

	t0 = rte_rdtsc_precise();
	for (int i = 0; i < CALLS; i++)
		acc += fn();
	t1 = rte_rdtsc_precise();
	sink = acc;
	return (double)(t1 - t0) * ns_per_cycle / CALLS;
}

static void

	one_rep(fn, ns_per_cycle);                  /* 1. warm-up, discarded */
	for (int r = 0; r < REPS; r++)              /* 2. N repetitions */
		v[r] = one_rep(fn, ns_per_cycle);
	report(name, v, REPS, "ns/call");           /* 3. median, min, max */
}

      How to measure on this machine (used by every later benchmark)

      The course machine is a 4-CPU virtual machine shared with other jobs, so a single run is noise. Every number published in this course follows these rules:

      1. Warm up once and throw the result away (caches, page faults, CPU frequency).
      2. Repeat at least 5 times (tsc_lab uses 7) with identical settings.
      3. Report the median, plus min and max to show the spread. Not the mean: one disturbed run moves the mean a lot, the median hardly.
      4. Do not oversubscribe: one busy lcore per CPU, and leave a CPU for control threads, unless oversubscription is the experiment.
      5. Time with the TSC around the whole region (rte_rdtsc_precise() at both ends), and repeat the operation enough times (here a million) that the cost of the clock itself does not matter.
      6. Expect noise from other processes; if min and max are far apart, say so, or run again.
      7. Never quote a number you did not measure, and label VM and software-driver numbers as such. ch22 goes much deeper (isolation, profiling, power).

      10Signals and a clean shutdown

      Polling loops never end by themselves, so Ctrl-C (SIGINT) is the usual way to stop a DPDK application. Two rules:

      1. The signal handler only sets a flag. A handler can interrupt any code, including code that holds a DPDK lock. Calling printf(), rte_eth_dev_stop() or rte_eal_cleanup() from it can deadlock or corrupt state. Storing to a lock-free atomic variable is safe.
      2. Every loop checks the flag and returns; the main lcore waits for all of them (rte_eal_mp_wait_lcore()), then stops devices (ch8, ch12) and calls rte_eal_cleanup() once.

 *   1. what rte_eal_init() returned and the basic lcore facts
 *   2. the lcore table: lcore id -> CPU, NUMA socket, role, state
 *   3. rte_eal_remote_launch() + rte_eal_wait_lcore() collecting return values
 *   4. the WAIT/RUNNING state machine and the -EBUSY error
 *   5. rte_eal_mp_remote_launch(CALL_MAIN) and per-lcore TLS (RTE_DEFINE_PER_LCORE)
 *   6. a plain pthread before and after rte_thread_register()
 *   7. a control thread made with rte_thread_create_control()
 *   8. rte_lcore_dump() and rte_eal_cleanup()
 *
 * Serve mode (-- --serve N) keeps every worker busy-polling until SIGINT /
 * SIGTERM or N seconds pass, so run.sh can look at the threads in /proc.
 * It also shows the right way to stop: the signal handler only sets an
 * atomic flag, the lcores see it and return, then main cleans up.
 */
#define _GNU_SOURCE      /* sched_getaffinity, sched_getcpu, CPU_* */
#include <errno.h>
#include <inttypes.h>
#include <pthread.h>
#include <sched.h>
#include <signal.h>
#include <stdbool.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>

#include <rte_common.h>
#include <rte_cycles.h>
#include <rte_eal.h>
#include <rte_errno.h>
#include <rte_launch.h>
#include <rte_lcore.h>
#include <rte_pause.h>
#include <rte_per_lcore.h>
#include <rte_stdatomic.h>
#include <rte_thread.h>

/* ---- shared state ------------------------------------------------------ */

/* Set by the signal handler, read by every lcore. A lock-free atomic int is
 * async-signal-safe to store to; DPDK calls are not. */
static RTE_ATOMIC(int) quit;

/* Used by the -EBUSY demo: the worker spins until main sets it. */
static RTE_ATOMIC(int) go;

/* Per-thread (TLS) counter: every thread has its own copy, no sharing. */
static RTE_DEFINE_PER_LCORE(uint64_t, calls);

static const char *
role_name(enum rte_lcore_role_t r)
{
	switch (r) {
	case RTE_LCORE_ROLE_RTE:     return "RTE";
	case RTE_LCORE_ROLE_OFF:     return "OFF";
	case RTE_LCORE_ROLE_SERVICE: return "SERVICE";
	case RTE_LCORE_ROLE_NON_EAL: return "NON_EAL";
	}
	return "?";
}

static const char *
state_name(enum rte_lcore_state_t s)
{
	return s == WAIT ? "WAIT" : s == RUNNING ? "RUNNING" : "?";
}

/* Print the CPUs the *calling thread* may run on, e.g. "1" or "0,3". */
static void
print_my_cpus(const char *who)
{
	cpu_set_t set;
	char buf[64] = "";
	int n = 0;

	CPU_ZERO(&set);
	sched_getaffinity(0, sizeof(set), &set);   /* 0 = this thread */
	for (int c = 0; c < CPU_SETSIZE && n < (int)sizeof(buf) - 4; c++)
		if (CPU_ISSET(c, &set))
			n += snprintf(buf + n, sizeof(buf) - n, "%s%d", n ? "," : "", c);
	printf("  %-28s lcore_id=%-3d allowed CPUs=%s\n", who,
	       (int)rte_lcore_id(), buf);
}

/* ---- work functions (lcore_function_t: int f(void *)) ------------------ */

/* 3. Returns a value main can collect with rte_eal_wait_lcore(). */
static int
work_square(void *arg)
{
	unsigned int id = rte_lcore_id();
	(void)arg;
	printf("  [lcore %u on CPU %d] running work_square\n", id, sched_getcpu());
	return 100 + (int)(id * id);
}

/* 4. Spins until main says "go", so main can observe RUNNING. */
static int
work_wait_for_go(void *arg)
{
	(void)arg;
	while (!rte_atomic_load_explicit(&go, rte_memory_order_acquire))
		rte_pause();
	return 7;
}

/* 5. Runs on every lcore including main (CALL_MAIN). */
static int
work_count(void *arg)
{
	int n = *(int *)arg;
	for (int i = 0; i < n; i++)
		RTE_PER_LCORE(calls)++;
	printf("  [lcore %u] my TLS counter = %" PRIu64 "\n",
	       rte_lcore_id(), RTE_PER_LCORE(calls));
	return 0;
}

/* Serve mode: a typical polling loop that checks the quit flag. */
static int
work_poll(void *arg)
{
	uint64_t loops = 0;
	(void)arg;
	while (!rte_atomic_load_explicit(&quit, rte_memory_order_relaxed)) {
		loops++;            /* a real app would rte_eth_rx_burst() here */
		rte_pause();
	}
	printf("  [lcore %u] saw quit after %" PRIu64 " loops\n",
	       rte_lcore_id(), loops);
	return 0;
}

/* ---- threads that are not EAL lcores ----------------------------------- */

/* 6. A plain pthread: no lcore id until it registers. */
static void *
plain_thread(void *arg)
{
	(void)arg;
	print_my_cpus("pthread before register:");
	if (rte_thread_register() != 0) {
		printf("  rte_thread_register failed: %s\n", rte_strerror(rte_errno));
		return NULL;
	}
	printf("  pthread after register:      lcore_id=%u role=%s\n",
	       rte_lcore_id(), role_name(rte_eal_lcore_role(rte_lcore_id())));
	rte_thread_unregister();
	printf("  pthread after unregister:    lcore_id=%d\n", (int)rte_lcore_id());
	return NULL;
}

/* 7. A control thread: rte_thread_func returns uint32_t. */
static uint32_t
control_thread(void *arg)
{
	int serve = *(int *)arg;
	print_my_cpus("control thread 'ch03-ctl':");
	/* In serve mode it stays alive so it shows up in /proc. */
	while (serve && !rte_atomic_load_explicit(&quit, rte_memory_order_relaxed))
		usleep(10 * 1000);
	return 42;
}

/* ---- signals ------------------------------------------------------------ */

static void
on_signal(int sig)
{
	/* Only async-signal-safe work here: store a flag. No printf, no rte_*. */
	(void)sig;
	rte_atomic_store_explicit(&quit, 1, rte_memory_order_relaxed);
}

/* ---- main --------------------------------------------------------------- */

int
main(int argc, char **argv)
{
	unsigned int id;
	int serve_secs = 0;
	int ret = rte_eal_init(argc, argv);

	if (ret < 0) {
		fprintf(stderr, "rte_eal_init failed: %s\n", rte_strerror(rte_errno));
		return 1;
	}
	/* EAL consumed 'ret' arguments; what is left belongs to us. */
	argc -= ret;
	argv += ret;
	if (argc >= 3 && strcmp(argv[1], "--serve") == 0)
		serve_secs = atoi(argv[2]);

	signal(SIGINT, on_signal);
	signal(SIGTERM, on_signal);

	printf("\n== 1. rte_eal_init returned %d (arguments consumed)\n", ret);
	printf("  main lcore=%u  lcore count=%u  TSC hz=%" PRIu64 "\n",
	       rte_get_main_lcore(), rte_lcore_count(), rte_get_tsc_hz());

	printf("\n== 2. lcore table (RTE_LCORE_FOREACH)\n");
	printf("  lcore  cpu  socket  role     state\n");
	RTE_LCORE_FOREACH(id)
		printf("  %5u  %3d  %6u  %-7s  %s\n", id, rte_lcore_to_cpu_id(id),
		       rte_lcore_to_socket_id(id), role_name(rte_eal_lcore_role(id)),
		       id == rte_get_main_lcore() ? "(main)" :
		       state_name(rte_eal_get_lcore_state(id)));
	print_my_cpus("main thread:");

	if (serve_secs > 0) {
		int one = 1;
		rte_thread_t ctl;
		uint64_t end;

		printf("\n== serve mode: pid %d, polling for up to %d s (SIGINT stops)\n",
		       (int)getpid(), serve_secs);
		fflush(stdout);
		rte_thread_create_control(&ctl, "ch03-ctl", control_thread, &one);
		rte_eal_mp_remote_launch(work_poll, NULL, SKIP_MAIN);
		end = rte_get_tsc_cycles() + (uint64_t)serve_secs * rte_get_tsc_hz();
		while (!rte_atomic_load_explicit(&quit, rte_memory_order_relaxed) &&
		       rte_get_tsc_cycles() < end)
			usleep(10 * 1000);       /* main just supervises */
		rte_atomic_store_explicit(&quit, 1, rte_memory_order_relaxed);
		rte_eal_mp_wait_lcore();          /* every worker back in WAIT */
		rte_thread_join(ctl, NULL);
		printf("  all lcores stopped; cleanup=%d\n", rte_eal_cleanup());
		return 0;
	}

	printf("\n== 3. remote_launch + wait_lcore (return values)\n");
	RTE_LCORE_FOREACH_WORKER(id) {
		ret = rte_eal_remote_launch(work_square, NULL, id);
		if (ret != 0)
			printf("  launch on %u failed: %d\n", id, ret);
	}
	RTE_LCORE_FOREACH_WORKER(id)
		printf("  rte_eal_wait_lcore(%u) = %d\n", id, rte_eal_wait_lcore(id));

	printf("\n== 4. state machine and -EBUSY\n");
	id = rte_get_next_lcore(-1, 1, 0);          /* first worker */
	if (id < RTE_MAX_LCORE) {
		printf("  before launch: lcore %u is %s\n", id,
		       state_name(rte_eal_get_lcore_state(id)));
		rte_eal_remote_launch(work_wait_for_go, NULL, id);
		printf("  after launch:  lcore %u is %s\n", id,
		       state_name(rte_eal_get_lcore_state(id)));
		ret = rte_eal_remote_launch(work_square, NULL, id);
		printf("  second launch while RUNNING returns %d (-EBUSY is %d)\n",
		       ret, -EBUSY);
		rte_atomic_store_explicit(&go, 1, rte_memory_order_release);
		printf("  rte_eal_wait_lcore(%u) = %d\n", id, rte_eal_wait_lcore(id));
		printf("  after wait:    lcore %u is %s\n", id,
		       state_name(rte_eal_get_lcore_state(id)));
	}

	printf("\n== 5. mp_remote_launch(CALL_MAIN) + RTE_PER_LCORE\n");
	{
		int n = 3;
		/* main runs work_count itself, synchronously, after waking workers */
		rte_eal_mp_remote_launch(work_count, &n, CALL_MAIN);
		rte_eal_mp_wait_lcore();
		rte_eal_mp_remote_launch(work_count, &n, CALL_MAIN);
		rte_eal_mp_wait_lcore();
	}

	printf("\n== 6. a non-EAL pthread and rte_thread_register()\n");
	{
		pthread_t t;
		pthread_create(&t, NULL, plain_thread, NULL);
		pthread_join(t, NULL);
	}

	printf("\n== 7. rte_thread_create_control()\n");
	{
		rte_thread_t ctl;
		uint32_t rv = 0;
		int zero = 0;
		ret = rte_thread_create_control(&ctl, "ch03-ctl", control_thread, &zero);
		if (ret == 0) {
			rte_thread_join(ctl, &rv);
			printf("  control thread returned %u\n", rv);
		} else {
			printf("  rte_thread_create_control failed: %d\n", ret);
		}
	}

	printf("\n== 8. rte_lcore_dump() and rte_eal_cleanup()\n");
	rte_lcore_dump(stdout);
	ret = rte_eal_cleanup();
	printf("  rte_eal_cleanup() = %d\n", ret);
	return 0;
}
      /* SPDX-License-Identifier: BSD-3-Clause
 *
 * log_lab.c - Chapter 3: DPDK logging from the application's side.
 *
 *   ./log_lab -l 0 --no-pci --no-huge -m 64 --file-prefix=ch03-log
 *   ./log_lab -l 0 --no-pci --no-huge -m 64 --file-prefix=ch03-log \
 *             --log-level='user.ch03*:debug'
 *
 * Shows:
 *   - registering two dynamic logtypes with RTE_LOG_REGISTER_SUFFIX
 *     ("user.ch03app" and "user.ch03app.rx")
 *   - the RTE_LOGTYPE_<NAME> naming trick that RTE_LOG / RTE_LOG_LINE need
 *   - which levels pass by default and with --log-level patterns
 *   - changing levels at run time with rte_log_set_level_pattern()
 *   - rte_log_can_log() to skip expensive formatting
 *   - redirecting all DPDK logs to a FILE* with rte_openlog_stream()
 */
#include <inttypes.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#include <rte_eal.h>
#include <rte_errno.h>
#include <rte_log.h>

/*
 * RTE_LOG_REGISTER_SUFFIX(var, suffix, level) registers the name
 *     RTE_LOG_DEFAULT_LOGTYPE "." suffix
 * Inside DPDK the build system defines RTE_LOG_DEFAULT_LOGTYPE (lib.eal,
 * pmd.net.null, ...). An application must define it itself, before use.
 * Here the prefix is "user", so the names become user.ch03app and
 * user.ch03app.rx. The registration runs as a constructor, before main().
 */
#define RTE_LOG_DEFAULT_LOGTYPE user
RTE_LOG_REGISTER_SUFFIX(app_logtype, ch03app, INFO);
RTE_LOG_REGISTER_SUFFIX(rx_logtype, ch03app.rx, WARNING);

/* RTE_LOG(l, t, ...) pastes RTE_LOGTYPE_##t, so give each type a short name.
 * The short name is also the prefix printed on each line ("APP: ..."). */
#define RTE_LOGTYPE_APP app_logtype
#define RTE_LOGTYPE_RX  rx_logtype

/* The usual app-wide wrappers. RTE_LOG_LINE adds the '\n' for you and
 * refuses (at compile time) a format string that already ends in '\n'. */
#define APP_LOG(level, ...) RTE_LOG_LINE(level, APP, __VA_ARGS__)
#define RX_LOG(level, ...)  RTE_LOG_LINE(level, RX, __VA_ARGS__)

static void
emit_all(const char *tag)
{
	printf("--- %s\n", tag);
	fflush(stdout);
	APP_LOG(ERR,     "app ERR     (level 4)");
	APP_LOG(WARNING, "app WARNING (level 5)");
	APP_LOG(NOTICE,  "app NOTICE  (level 6)");
	APP_LOG(INFO,    "app INFO    (level 7)");
	APP_LOG(DEBUG,   "app DEBUG   (level 8)");
	RX_LOG(WARNING,  "rx  WARNING (level 5)");
	RX_LOG(INFO,     "rx  INFO    (level 7)");
	RX_LOG(DEBUG,    "rx  DEBUG   (level 8)");
	fflush(stderr);
}

static uint64_t
expensive_summary(void)
{
	uint64_t s = 0;
	for (uint64_t i = 0; i < 1000000; i++)
		s += i ^ (s >> 3);
	return s;
}

int
main(int argc, char **argv)
{
	int ret = rte_eal_init(argc, argv);
	FILE *f;
	char line[256];

	if (ret < 0) {
		fprintf(stderr, "rte_eal_init failed: %s\n", rte_strerror(rte_errno));
		return 1;
	}
	/* DPDK logs go to stderr (unbuffered); make stdout line-buffered so the
	 * two streams stay in order when both are piped into one file. */
	setvbuf(stdout, NULL, _IOLBF, 0);

	printf("logtype ids: user.ch03app=%d user.ch03app.rx=%d (dynamic ids)\n",
	       app_logtype, rx_logtype);
	printf("current levels: app=%d rx=%d global=%d\n",
	       rte_log_get_level(app_logtype), rte_log_get_level(rx_logtype),
	       (int)rte_log_get_global_level());

	emit_all("1. as registered (or as set by --log-level)");

	/* Change levels at run time with a glob pattern. */
	rte_log_set_level_pattern("user.ch03app*", RTE_LOG_DEBUG);
	emit_all("2. after rte_log_set_level_pattern(\"user.ch03app*\", DEBUG)");

	rte_log_set_level(rx_logtype, RTE_LOG_ERR);
	emit_all("3. after rte_log_set_level(rx, ERR)");

	/* Guard expensive work: only compute if the message would be printed. */
	printf("--- 4. rte_log_can_log guard\n");
	if (rte_log_can_log(rx_logtype, RTE_LOG_DEBUG))
		RX_LOG(DEBUG, "summary=%" PRIu64, expensive_summary());
	else
		printf("rx DEBUG is off: skipped expensive_summary()\n");
	if (rte_log_can_log(app_logtype, RTE_LOG_DEBUG))
		APP_LOG(DEBUG, "summary=%" PRIu64, expensive_summary());

	/* Redirect: every DPDK log line (EAL's too) now goes to the file. */
	printf("--- 5. rte_openlog_stream(file)\n");
	f = tmpfile();
	if (f == NULL)
		return 1;
	rte_openlog_stream(f);
	APP_LOG(NOTICE, "this line goes to the file, not stderr");
	RTE_LOG(WARNING, EAL, "even EAL lines follow the stream\n");
	rte_openlog_stream(NULL);                /* back to the default */
	APP_LOG(NOTICE, "back on the default stream");
	fflush(stderr);
	rewind(f);
	while (fgets(line, sizeof(line), f) != NULL)
		printf("file: %s", line);
	fclose(f);

	/* rte_log_list_types(out, prefix) prints EVERY dynamic type; 'prefix'
	 * is only text put in front of each name. We filter ourselves. */
	printf("--- 6. rte_log_list_types: our types and a few library types\n");
	f = tmpfile();
	if (f != NULL) {
		rte_log_list_types(f, "  ");
		rewind(f);
		while (fgets(line, sizeof(line), f) != NULL)
			if (strstr(line, "user.ch03") || strstr(line, "lib.eal") ||
			    strstr(line, "pmd.net.null"))
				printf("%s", line);
		fclose(f);
	}

	rte_eal_cleanup();
	return 0;
}
      /* SPDX-License-Identifier: BSD-3-Clause
 *
 * tsc_lab.c - Chapter 3: time in DPDK, and the course measurement recipe.
 *
 *   ./tsc_lab -l 0 --no-pci --no-huge -m 64 --file-prefix=ch03-tsc
 *
 * Part A: check rte_get_tsc_hz() against the kernel clock.
 * Part B: cost per call of four clocks (rte_rdtsc, rte_rdtsc_precise,
 *         rte_get_timer_cycles, clock_gettime(CLOCK_MONOTONIC)).
 * Part C: rte_delay_us_block() vs rte_delay_us_sleep(): same wall time,
 *         very different CPU time.
 *
 * "How to measure on this machine" (used by every later benchmark):
 *   1. warm up once and throw the result away,
 *   2. repeat N >= 5 times (here N = 7),
 *   3. report the median, and min and max to show the noise,
 *   4. use one lcore per CPU (no oversubscription),
 *   5. never publish a number you did not measure.
 */
#define _GNU_SOURCE
#include <inttypes.h>
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

#include <rte_cycles.h>
#include <rte_eal.h>
#include <rte_errno.h>

#define REPS   7            /* N measured repetitions (after 1 warm-up) */
#define CALLS  1000000      /* calls per repetition in part B */

static volatile uint64_t sink;   /* stops the compiler deleting the loops */

static int
cmp_double(const void *a, const void *b)
{
	double x = *(const double *)a, y = *(const double *)b;
	return (x > y) - (x < y);
}

/* Sort the samples and print "median (min .. max)". */
static void
report(const char *name, double *v, int n, const char *unit)
{
	qsort(v, n, sizeof(*v), cmp_double);
	printf("  %-34s median %8.2f %s   (min %8.2f, max %8.2f, N=%d)\n",
	       name, v[n / 2], unit, v[0], v[n - 1], n);
}

static uint64_t
now_ns(clockid_t c)
{
	struct timespec ts;
	clock_gettime(c, &ts);
	return (uint64_t)ts.tv_sec * 1000000000ull + ts.tv_nsec;
}

/* ---- the four clocks under test --------------------------------------- */
static inline uint64_t c_rdtsc(void)    { return rte_rdtsc(); }
static inline uint64_t c_precise(void)  { return rte_rdtsc_precise(); }
static inline uint64_t c_timer(void)    { return rte_get_timer_cycles(); }
static inline uint64_t c_mono(void)     { return now_ns(CLOCK_MONOTONIC); }

typedef uint64_t (*clock_fn)(void);

/* One repetition: CALLS calls, timed with the TSC; returns ns per call. */
static double
one_rep(clock_fn fn, double ns_per_cycle)
{
	uint64_t acc = 0, t0, t1;

	t0 = rte_rdtsc_precise();
	for (int i = 0; i < CALLS; i++)
		acc += fn();
	t1 = rte_rdtsc_precise();
	sink = acc;
	return (double)(t1 - t0) * ns_per_cycle / CALLS;
}

static void
bench_clock(const char *name, clock_fn fn, double ns_per_cycle)
{
	double v[REPS];

	one_rep(fn, ns_per_cycle);                  /* 1. warm-up, discarded */
	for (int r = 0; r < REPS; r++)              /* 2. N repetitions */
		v[r] = one_rep(fn, ns_per_cycle);
	report(name, v, REPS, "ns/call");           /* 3. median, min, max */
}

/* Part C: wall time and CPU time of one delay call, in microseconds. */
static void
bench_delay(const char *name, void (*delay)(unsigned int), unsigned int us)
{
	double wall[5], cpu[5];

	delay(us);                                   /* warm-up */
	for (int r = 0; r < 5; r++) {
		uint64_t w0 = now_ns(CLOCK_MONOTONIC);
		uint64_t c0 = now_ns(CLOCK_THREAD_CPUTIME_ID);
		delay(us);
		cpu[r]  = (now_ns(CLOCK_THREAD_CPUTIME_ID) - c0) / 1000.0;
		wall[r] = (now_ns(CLOCK_MONOTONIC) - w0) / 1000.0;
	}
	printf("  %s(%u):\n", name, us);
	report("    wall time", wall, 5, "us");
	report("    CPU time of this thread", cpu, 5, "us");
}

int
main(int argc, char **argv)
{
	int ret = rte_eal_init(argc, argv);
	uint64_t hz;
	double ns_per_cycle;

	if (ret < 0) {
		fprintf(stderr, "rte_eal_init failed: %s\n", rte_strerror(rte_errno));
		return 1;
	}
	setvbuf(stdout, NULL, _IOLBF, 0);
	hz = rte_get_tsc_hz();
	ns_per_cycle = 1e9 / (double)hz;

	printf("== A. TSC frequency\n");
	printf("  rte_get_tsc_hz()   = %" PRIu64 " Hz\n", hz);
	printf("  rte_get_timer_hz() = %" PRIu64 " Hz (timer source = TSC here)\n",
	       rte_get_timer_hz());
	{
		double v[REPS];
		for (int r = 0; r < REPS; r++) {
			uint64_t n0 = now_ns(CLOCK_MONOTONIC), t0 = rte_rdtsc_precise();
			rte_delay_us_block(20000);                 /* 20 ms */
			uint64_t n1 = now_ns(CLOCK_MONOTONIC), t1 = rte_rdtsc_precise();
			v[r] = (double)(t1 - t0) / (double)(n1 - n0) * 1000.0; /* MHz */
		}
		report("TSC measured vs CLOCK_MONOTONIC", v, REPS, "MHz");
	}

	printf("\n== B. cost of reading a clock (%d calls per repetition)\n", CALLS);
	bench_clock("rte_rdtsc()", c_rdtsc, ns_per_cycle);
	bench_clock("rte_rdtsc_precise()", c_precise, ns_per_cycle);
	bench_clock("rte_get_timer_cycles()", c_timer, ns_per_cycle);
	bench_clock("clock_gettime(CLOCK_MONOTONIC)", c_mono, ns_per_cycle);

	printf("\n== C. busy delay vs sleeping delay\n");
	bench_delay("rte_delay_us_block", rte_delay_us_block, 10000);
	bench_delay("rte_delay_us_sleep", rte_delay_us_sleep, 10000);

	rte_eal_cleanup();
	return 0;
}

      Common pitfalls

      • "lcore 4 unavailable ... invalid coremask or core-list parameter": you asked for a CPU the machine does not have, or one outside the process's allowed CPUs (a container or taskset can restrict them). Check nproc and grep Cpus_allowed_list /proc/self/status.
      • "Main lcore is not enabled for DPDK": --main-lcore names an lcore that is not in -l.
      • Using -c/-s from an old tutorial: works today with a deprecation warning, will break later. Use -l and -S.
      • Confusing lcore id and CPU id: with -R or @ they differ. Use rte_lcore_to_cpu_id() when you need the CPU, and rte_lcore_id() to index per-lcore arrays.
      • All CPUs given to lcores: control threads then share the main lcore's CPU. Interrupts, alarms, telemetry and multi-process requests get delayed, and a busy-polling main lcore gets interrupted. Leave one CPU free.
      • Launching on a busy worker: rte_eal_remote_launch() returns -EBUSY and does nothing. Check the return value, and call rte_eal_wait_lcore() first.
      • Assuming rte_lcore_count() equals the number of workers + 1: service lcores are counted but not visited by RTE_LCORE_FOREACH.
      • Calling DPDK functions from a plain pthread that needs an lcore id (mempool caches, timers): register it with rte_thread_register(), or keep that work on lcores.
      • RTE_LOG_LINE with "...\n": compile error "This log format string contains a \n". Drop the newline. Also define RTE_LOGTYPE_<NAME>, and RTE_LOG_DEFAULT_LOGTYPE before RTE_LOG_REGISTER_SUFFIX.
      • Work inside a signal handler: only set an atomic flag there.
      • Leftover hugepage files after a crash: remove /dev/hugepages/<prefix>map_* and /var/run/dpdk/<prefix> only when no process with that prefix runs.
      • Timing with rte_delay_us() in a shared environment: it spins and burns a whole CPU. Use rte_delay_us_sleep() when you just need to wait.

      Summary
      • rte_eal_init() parses options, detects CPUs, creates the runtime directory and shared config, starts the interrupt and multi-process threads, scans buses, picks the IOVA mode, sets up memory, measures the TSC, starts the lcore threads, probes devices and starts telemetry. It returns the number of arguments it consumed.
      • An lcore is a DPDK thread id with a cpuset; a CPU is a hardware thread. -l/--lcores with @ and groups maps them; --main-lcore and -R adjust ids; -c/-s are deprecated.
      • Workers sleep in WAIT until rte_eal_remote_launch(); they return to WAIT when the function returns; rte_eal_wait_lcore() collects the return value; launching a RUNNING worker gives -EBUSY.
      • A process has EAL threads (lcores), control threads (dpdk-intr, dpdk-mp-msg, dpdk-telemet-v2, yours) on the leftover CPUs, and possibly registered non-EAL threads.
      • Logs pass two level checks (global and per logtype). Register user.* types with RTE_LOG_REGISTER_SUFFIX, log with RTE_LOG_LINE, steer with --log-level globs, regexes or a global number.
      • Read time with rte_rdtsc() (about 12 ns here), fence measurements with rte_rdtsc_precise(), and measure with warm-up, N ≥ 5, median, min and max.
      • Stop with a flag set by the signal handler, wait for all lcores, then rte_eal_cleanup(); otherwise hugepage and runtime files are left behind.
