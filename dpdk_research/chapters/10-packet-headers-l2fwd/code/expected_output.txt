== 1. one's-complement sum of the 10 header words (network order)
  word 0  bytes 45 00  = 0x4500   running sum 0x04500
  word 1  bytes 00 73  = 0x0073   running sum 0x04573
  word 2  bytes 00 00  = 0x0000   running sum 0x04573
  word 3  bytes 40 00  = 0x4000   running sum 0x08573
  word 4  bytes 40 11  = 0x4011   running sum 0x0c584
  word 5  bytes 00 00  = 0x0000   running sum 0x0c584   (checksum field, 0 while computing)
  word 6  bytes c0 a8  = 0xc0a8   running sum 0x1862c
  word 7  bytes 00 01  = 0x0001   running sum 0x1862d
  word 8  bytes c0 a8  = 0xc0a8   running sum 0x246d5
  word 9  bytes 00 c7  = 0x00c7   running sum 0x2479c
  32-bit sum            = 0x0002479c
  fold: 0x479c + 0x2    = 0x479e  (add the carries back in)
  invert                = 0xb861  <- the checksum, in network order

== 2. the library (this CPU is little-endian)
  rte_raw_cksum(hdr, 20)   = 0x9e47  (folded, NOT inverted, host-loaded words)
  rte_ipv4_cksum(hdr)      = 0x61b8
  rte_ipv4_cksum_simple()  = 0x61b8
  rte_be_to_cpu_16(lib)    = 0xb861  == by hand 0xb861 ? yes

== 3. storing it: write the value exactly as returned
  hdr_checksum = rte_ipv4_cksum()      -> bytes b8 61 on the wire (correct)
  hdr_checksum = rte_cpu_to_be_16(...) -> bytes 61 b8 (WRONG: swapped twice)
  why: one's-complement sums are byte-order independent; summing
  byte-swapped words gives the byte-swapped sum, so the result is
  already in 'memory order'. Swapping it again breaks it.

== 4. verification: sum over a header that INCLUDES its checksum
  correct header : rte_raw_cksum = 0xffff (0xffff means valid)
  swapped cksum  : rte_raw_cksum = 0x56a9 (invalid)

== 5. bug: recomputing without zeroing hdr_checksum first
  rte_ipv4_cksum() on the unzeroed header = 0x0000 (should be 0x61b8)
  rte_ipv4_cksum_simple() ignores the field = 0x61b8

== 6. router step: TTL 64 -> 63, incremental update (RFC 1624 eqn. 3)
  HC=0xb861  m=0x4011  m'=0x3f11
  ~HC + ~m + m' = 0x479e + 0xbfee + 0x3f11 = 0x1469d -> fold 0x469e -> ~ 0xb961
  full recompute = 0xb961   incremental = 0xb961   MATCH
  (RFC 1141 shortcut for TTL-1: HC + 0x0100 = 0xb961)

== 7. UDP checksum = sum(pseudo-header) + sum(UDP header + data)
  pseudo-header = src 192.168.0.1, dst 192.168.0.199, zero, proto 17, len 11
  rte_ipv4_phdr_cksum()   = 0x3582 (not inverted; also what TX offload
                            drivers want pre-filled, see ch19)
  rte_raw_cksum(udp, 11)  = 0x76d8 (odd length: last byte padded with 0)
  rte_ipv4_udptcp_cksum() = 0x53a5  = ~fold(0x3582 + 0x76d8)
  rte_ipv4_udptcp_cksum_verify() = 0 (0 = valid)
  after flipping 1 payload bit: verify = -1
  after changing only the IP dst (pseudo-header!): verify = -1
